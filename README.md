# Claude Codeで始めるWeb制作副業

初心者が、週20時間くらいでホームページ制作の副業を始めるためのリポジトリです。

## 中身

| パス | 内容 |
|---|---|
| `index.html` | ポートフォリオサイト（自分の紹介・料金・実績） |
| `works/cafe/` | 制作サンプル①：カフェの紹介ページ |
| `works/seitai/` | 制作サンプル②：整体院の集客LP |
| `docs/coconala-listing.md` | ココナラに出品するときの文章テンプレート |

## 4週間プラン（週20時間）

### 1週目：準備（ポートフォリオを公開する）
- [ ] `index.html` の `[あなたの名前]` を書き換える
- [ ] GitHub Pagesで公開する（Settings → Pages → Branch を選んで Save）
- [ ] スマホでサンプルサイトを見て、仕組みを理解する
- [ ] Claude Codeに「このサイトのここを変えて」と頼んで、修正の練習をする

### 2週目：サンプルを増やす
- [ ] 美容室、塾、飲食店など、別の業種のサンプルをClaude Codeで2〜3個作る
- [ ] 地元のお店のサイトを見て「自分ならこう作る」と考えてみる
- [ ] HTML/CSSの基本を少しずつ覚える（Claude Codeに「このコードを説明して」と聞く）

### 3週目：出品する
- [ ] ココナラに登録し、プロフィールを作る
- [ ] `docs/coconala-listing.md` をもとに出品する
- [ ] 最初は安め（5,000〜10,000円）にして、実績を作る

### 4週目：受注・納品
- [ ] 依頼が来たら、ヒアリング → Claude Codeで制作 → 確認 → 納品
- [ ] 依頼がなければ、クラウドワークス・ランサーズの案件に提案する（1日3件くらい）
- [ ] 知り合いのお店に「無料か格安で作らせてください」と声をかけるのも有効

## Claude Codeへの頼み方の例

```
works/ に美容室のサンプルLPを作って。落ち着いた大人向けの雰囲気で、
メニュー・料金・スタッフ紹介・予約ボタンを入れて。スマホで見やすくして。
```

```
works/cafe/index.html のメイン画像の文字をもっと大きくして、色を緑系に変えて。
```

## 注意点
- サンプルは架空のお店です。実在のお店の名前やロゴを勝手に使わないでください
- 画像はUnsplashなどのフリー素材を使っています。お客様の案件では、お客様の写真かライセンスを確認した素材を使ってください
- 納品前に、必ずスマホとパソコンの両方で表示を確認してください
