## 決めたこと

- **ジャンル**：サバイバー系（ヴァンサバ系）×妖怪コレクター
  - 操作は移動だけ、攻撃は自動
  - 敵妖怪のHPを削ると自動で「封じる」（捕獲）演出が入り、仲間になる。捕獲用の別ボタンは作らない
  - 捕獲した妖怪＝武器スロット。妖怪ごとに違う自動攻撃パターンを持つ
  - プレイ外に「妖怪図鑑」があり、妖怪同士を合成して新しい妖怪に進化させられる。これが周回のモチベーションになる
- **世界観**：和風・妖怪モチーフ。曰くつきの場所が舞台（実話怪談チャンネルの世界観と相性がいいが、企画としては独立させる。施工管理の仕事ネタは使わない）
- **絵**：AI生成＋簡単な加工で素材を作る（ひかるは絵を描かない前提）
- **リリース先**：モバイル（iOS/Android）に変更。PC版は見送り（9/28に方針転換）
  - タッチ操作前提の画面設計（仮想スティックなど）が必要
  - App Store/Google Playの審査、年齢レーティング、ガチャ的課金をするなら確率表示（景品表示法）の対応が必要になる
- **エンジン**：Godot（無料・軽量。iOS/Androidエクスポートにも対応）
- **開発ペース**：週5〜10時間くらいを想定
- **競争要素**：非同期闘技場（ゴーストバトル）方式を入れる
  - 捕まえた妖怪パーティの強さを「戦闘力」という1つの数値にまとめる（レベル・レア度・合成度から算出）
  - 他プレイヤーの戦闘力データのスナップショットを定期的にサーバーに集めておき、プレイヤーはそれ相手にシミュレーション戦闘を仕掛けてランキングを上げる
  - リアルタイム対戦・マッチングはしない（個人開発には重すぎるため）
  - 実現にはFirebase・Supabaseなどの既製バックエンドサービスを使う想定。今までの「1人で完結するゲーム」から一歩踏み出すので、開発スコープが増える点に注意
  - 補足：ランキング（スコアボード）や週替わりシード縛りチャレンジも、通信不要で作れる競争要素として検討中
- **強さの決まり方（確定）**：最終的な戦闘力の到達点は無課金・課金プレイヤーで同じ。課金は「そこに早く着く」ための時短のみで、恒久的な強さの差は作らない
