# 怖い話チャンネル 企画書＋1本目の台本

## チャンネル設計

### ジャンル
**人怖（実話風の、人間が怖い話）**
- 幽霊などの演出コストが要らず、身近な設定で書ける
- 「先が気になって最後まで見る」ため視聴維持率が伸びやすく、YouTubeのアルゴリズムと相性が良い

### 投稿頻度
週2本を目標（無理せず続けることを優先。慣れてきたら週3本に増やす）

### 動画の長さ
1本 8〜10分程度
- YouTubeで中間広告（インストリーム広告）を入れられる目安が8分以上のため
- 長すぎると台本作りが負担になるので、最初は6〜8分から始めてOK

### 映像スタイル（コスト最小構成）
テロップ＋簡単な背景＋BGM＋ナレーションのみ。人物イラストや複雑なアニメーションは不要。
- **ナレーション**：VOICEVOX（無料の音声合成ソフト。ずんだもん・四国めたんなどが人気）
- **背景**：暗めの単色 or フリー素材の夜道・部屋の写真（Unsplash、pixabayなど商用利用可の無料素材）
- **BGM・効果音**：YouTubeオーディオライブラリ、フリー効果音サイト（効果音ラボなど）の「不穏な音」「衝撃音」
- **編集**：CapCut（無料・スマホでもPCでも可）

### チャンネルコンセプト（仮）
チャンネル名例：「夜更けの怖い話」「実話怪談ラジオ」など
毎回「〇〇な話」という一言タイトルで統一し、シリーズ感を出す

### 台本の型（テンプレート）
1. **導入（15〜20秒）**：「これは私が◯年前に体験した話です」など、状況の提示
2. **本編前半**：違和感の描写（普通の日常に、小さな異常が混ざり始める）
3. **本編後半**：異常がエスカレートし、恐怖のピークへ
4. **オチ**：短く、余韻を残して終わる（説明しすぎない）
5. **エンディング（10秒）**：「チャンネル登録と高評価、よろしくお願いします」＋次回予告

### 収益化について（注意点）
YouTubeパートナープログラムの条件（登録者1,000人＋直近12ヶ月の総再生時間4,000時間、またはショート視聴回数の条件）を満たすまでは広告収益は入りません。最初の数ヶ月は無収益が前提と考え、継続を優先してください。

## 1本目の台本：「引っ越し先の郵便受け」

**想定尺**：6〜7分（ナレーション文字数の目安：約1,800〜2,200字）

```
これは、私が去年、一人暮らしを始めたときに体験した話です。

社会人になって、初めて借りたアパート。
築年数は古いけど、駅から近くて、家賃も安い。
内見のときは特に何も感じませんでした。

引っ越して一週間ほど経った頃、郵便受けを開けると、
見覚えのない名前宛ての手紙が届いていました。
「佐野様」と書かれています。
私の苗字ではありません。

前の住人宛ての誤配だろうと思って、
郵便受けの横にある「転居先不明」の箱に入れておきました。

でも、その翌週も、また同じ名前の手紙が届いていました。
今度は速達で。

不動産屋に電話をして聞いてみると、
「あの部屋、前の住人が退去してからもう半年経ってますよ。
　郵便局にも転送届は出してもらってるはずなんですけどね」
と言われました。

半年前に退去した人宛ての手紙が、
なぜ今になって、しかも速達で届くのか。
少し気味が悪かったですが、その時はまだ、
「郵便局の手違いだろう」くらいにしか思っていませんでした。

異変に気づいたのは、それから数日後の深夜でした。

トイレに起きたとき、玄関の郵便受けのあたりから、
コトン、と小さな音がしたんです。
こんな時間に、誰かがポストに何かを入れている。

怖くなって、ドアスコープからそっと外を覗きました。
廊下には誰もいません。
でも、郵便受けの蓋が、まだ小さく揺れていました。

翌朝、恐る恐る郵便受けを開けると、
また「佐野様」宛ての手紙が入っていました。
消印はありません。
つまり、誰かが直接、手で投函したということです。

さすがに怖くなって、大家さんに相談しました。
大家さんは少し言いにくそうにしながら、こう言いました。

「実はその佐野さんって方、あなたの前にその部屋に住んでた方なんですけど……
　退去の連絡もないまま、ある日突然いなくなってしまって。
　荷物も置いたままだったので、家族の方に連絡して、
　こちらで処分させてもらったんです」

「もしかして、その手紙を届けに来てるのって……」
そう聞くと、大家さんは黙ってしまいました。

その日を境に、私は郵便受けを見るのが怖くなりました。
それでも生活のために毎日確認しないわけにはいきません。

一週間後、いつものように郵便受けを開けると、
今度は「佐野様」ではなく、
私の名前が書かれた手紙が入っていました。

差出人の欄には、何も書かれていません。
中を開けると、一枚の紙にこう書かれていました。

「次はあなたの番です」

私はその日のうちに、あの部屋を出ました。
今でも、夜遅くに郵便受けを覗くたびに、
あの音を思い出します。

コトン、という、小さな音を。
```

**テロップ・演出メモ**
- 「佐野様」の名前が出るたびに、少し強調する演出（文字を赤くする、効果音を入れる）を入れると印象に残りやすいです
- 「次はあなたの番です」の場面で、BGMを一瞬止めて無音にすると効果的です

**投稿時のタイトル案**
- 「【実話】引っ越し先の郵便受けに届いた、知らない名前の手紙」
- 「【人怖】前の住人宛ての手紙が、消印なしで届き続けた話」

**サムネイル文言案**
- 「その手紙、誰が届けてる？」
- 「郵便受けに、消印のない手紙が」
```
