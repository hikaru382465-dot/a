# 打ち合わせで聞かれそうなこと・答え方

初めてのお客さんとの商談で、よく聞かれる質問と答え方のメモ。事前に読んでおいて、その場で困らないようにする。

## 料金について

**Q. いくらかかりますか？**
> 1ページのご紹介サイトが15,000円、予約を増やしたい場合の縦長ページ（集客LP）が30,000円です。修正は2回まで無料で、3回目以降は1回3,000円になります。

**Q. 分割払いはできますか？**
> クラウドワークスを通しての決済になるので、分割については一括のみになります（クラウドワークス側の契約形態次第。事前に自分の設定を確認しておく）。

**Q. 追加費用はかかりますか？**
> ページ数を増やしたり、予約システムなどの機能を追加する場合は別途相談です。基本のプラン内容（お店の紹介・メニュー・アクセス・お問い合わせ導線）であれば追加費用はかかりません。

## 期間について

**Q. どれくらいで出来ますか？**
> 必要な情報（お店の名前、住所、営業時間、写真など）をいただいてから、早くて数日、通常1週間程度です。修正のやり取りを含めると2週間ほど見ていただくと安心です。

**Q. 急ぎでお願いできますか？**
> 内容次第では対応できる場合もありますが、平日は会社員として働いているため、返信や作業は主に平日夜・土日になります。あらかじめご了承ください、と伝えておく。

## できること・できないこと

**Q. ネットショップみたいに、オンラインで注文を受けたいのですが**
> サイト自体に決済機能を組み込むことは行っていませんが、BASEやSTORESなど外部の無料サービスと連携させる形でしたらご案内できます。

**Q. 予約フォームも作れますか？**
> フォームの仕組み自体は作りませんが、Googleフォームやホットペッパーなど外部の予約サービスへのリンクを設置する形で対応できます。

**Q. 独自ドメイン（〇〇.comみたいなの）は取ってもらえますか？**
> ドメインのご取得自体はお客様ご自身でお願いしています。取得後の設定はサポートします。

**Q. ロゴがないのですが**
> ロゴなしでも、お店の名前をテキストで見せる形で問題なく作れます。

## 公開・運用について

**Q. 公開後、自分たちで直せますか？**
> HTMLの知識がなくても、文章部分は書き換えやすい作りにしています。大きな変更やわからない部分は、修正オプション（3,000円/回）でも対応できます。

**Q. どこに公開されるんですか？サーバー代とかかかりますか？**
> GitHub PagesやXserverなど無料〜低価格の方法をご案内します。お客様名義で公開先を持っていただく形にするので、私が対応できなくなってもサイトがなくならず安心です。
