## 基本の提案文


## 応募方法が指定されている場合の版（項目に答える形式）

「自己紹介」「実績」「見積もり」「スケジュール」など、書く項目そのものが依頼文で決まっている案件向け。項目の名前や順番は、依頼文に合わせて変える。

```
はじめまして、ひかると申します。
【依頼文で一番大事そうなことを1行で。例：「コーヒーとパンの魅力が伝わるサイトを作りたい」というご希望】とのこと、ぜひ挑戦させてください。

■自己紹介・経歴
普段は会社員として【本業】をしております。副業でホームページ制作を行っており、お客様のご要望を正確にヒアリングして形にすることを大切にしています。
【この案件特有の業種・条件について、正直に一言。例：「〇〇業態での制作実績はまだございませんが、△△という形でカバーします」】

■過去の制作実績・ポートフォリオ
https://hikaru382465-dot.github.io/a/
【依頼の業種に近いサンプルがあれば、個別のURLも添える。例：カフェの依頼なら works/cafe/ へのリンク】

■概算のお見積もり
【ページ数・条件から出した金額】円を想定しております（ヒアリング後に正式な金額をご提示します）。

■スケジュール
【いつから着手できるか】。平日は夜、土日を中心に作業を行い、初稿を【日数】程度でご確認いただけるよう進めます。

【最後に一言、意気込みや案件への具体的な言及】。よろしくお願いいたします。
```

### 金額を聞かれたときの目安

ページ数や、素材（写真・ロゴ）を先方が用意してくれるかどうかで、作業量が変わる。

| 条件 | 目安の金額 |
|---|---|
| 1ページ、フリー素材で対応 | 20,000円（ココナラの最低価格に合わせる） |
| 1ページ、写真・ロゴあり | 25,000〜30,000円 |
| 3〜5ページ構成、写真・ロゴあり | 45,000〜60,000円 |
| 文章の下書きも任される場合 | 上記に5,000〜10,000円程度を上乗せ |

安く見せるために相場より下げすぎない。極端に安い金額は、「実績のない人」という印象をかえって強めてしまう。

### 実績を求められていて、実績がないとき

正直に書く。実績を偽ると、後で必ず不利になる（会話の中でボロが出る、納品物の質とのギャップで低評価になる、など）。代わりに、次のようなことでカバーする。

- 本業の経験が、その業種の理解に役立つ場合はそれを書く（例：施工管理の経験→建設業のお客様への理解）
- 依頼の業種に近いサンプルがあれば、そのページへの直接リンクを添える
- レスポンスの速さ、丁寧な進め方など、実績以外で信頼してもらえる材料を具体的に書く

「実績がなくてすみません」で終わらせず、必ず「その代わりに何をするか」まで書く。

## 提案するときのコツ

1. **最初の2〜3行は必ず書き換える**：依頼者は、自分の依頼文を読んでくれたかを最初の数行で判断します。コピペだと分かる提案は読まれません
2. **質問は1〜2個だけ**：質問が多すぎると面倒に思われます
3. **できないことは約束しない**：「検索で1位にします」「何でもできます」は書かない
4. **経験年数や実績を盛らない**：サンプルはサンプルとして見せる
5. **早めに提案する**：新しい案件ほど、早く提案した人が選ばれやすい

## 応募する案件の選び方

✅ 応募してよい案件
- 1ページのホームページ、LP（縦長の1ページ）
- 3〜5ページ程度の複数ページ構成（トップ・コンセプト・メニュー・アクセスなど）
- 文章・画像の差し替えなどの小さな修正
- HTML/CSSでの制作、または作り方の指定がない案件
- 写真・ロゴなどの素材を先方が用意してくれる案件（実際の素材で作れるので、むしろ良い案件）

❌ 最初は避ける案件
- WordPressでゼロから作る案件（慣れてから）
- ネットショップ、予約システム、会員登録などの機能を**自分でゼロから作る**案件
  - お金や個人情報を扱うので、不具合や情報流出が起きたときに責任を持てない
  - サーバーやデータベースの管理が、納品後もずっと必要になる
- 「納期3日以内」など、平日夜・土日では間に合わない案件
- 金額が極端に安い（作業量に対して1,000円など）案件

### ⭕ 専門のサービスを使う形なら対応できる

機能が必要な案件でも、すでにある専門のサービスを組み合わせれば、安全に対応できる。お金や個人情報は、そのサービスが管理してくれる。

| お客さんの要望 | 使うサービスの例 | 自分の仕事 |
|---|---|---|
| ネットショップがほしい | BASE、STORES、Shopify | ショップの開設と、ホームページからのリンク |
| 予約を受けたい | STORES予約、リザーブ、Googleフォーム | 予約ページの設定と、ホームページへのボタン設置 |
| 問い合わせを受けたい | Googleフォーム | フォームを作って、ホームページに埋め込む |

提案文では、例えば次のように書く。

```
ネットショップ機能は、BASE（無料で始められるネットショップ作成サービス）を使ってご用意し、ホームページからリンクする形をご提案します。お支払いや個人情報はBASEが安全に管理するため、安心してご利用いただけます。
```

- サービスの月額料金や決済手数料は、お客さんの負担になることを提案文に書いておく
- サービスのアカウントは**お客さん名義**で作ってもらう（自分の名義で作らない）
- 案件の依頼文に「WordPressで」「独自開発で」など作り方の指定がある場合は、この方法は使えないので応募しない

## 注意

- 提案文にメールアドレス・LINE・電話番号など、サイトの外で連絡を取る情報は書かない（規約違反になります）
- ポートフォリオのURLを載せてよいかは、各サイトのルールを確認する
