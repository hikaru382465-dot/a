```

【依頼文で一番大事そうなことを1行で。例：「新規のお客様に、お店の落ち着いた雰囲気を伝えたい」というご希望】とのこと、ぜひお手伝いさせてください。

## 短い版（小さな修正などの案件向け）

```
【依頼者の名前】様

はじめまして、ひかると申します。
【依頼内容を1行で。例：ホームページの営業時間とメニューの更新】のご依頼を拝見しました。

【対応方法を1〜2行で。例：いただいた内容の通りに文章を差し替え、スマホとパソコンの両方で表示を確認してから納品いたします。】

https://hikaru382465-dot.github.io/a/

平日は夜・土日の対応となりますが、丁寧に進めます。よろしくお願いいたします。

## 提案するときのコツ

1. **最初の2〜3行は必ず書き換える**：依頼者は、自分の依頼文を読んでくれたかを最初の数行で判断します。コピペだと分かる提案は読まれません
2. **質問は1〜2個だけ**：質問が多すぎると面倒に思われます
3. **できないことは約束しない**：「検索で1位にします」「何でもできます」は書かない
4. **経験年数や実績を盛らない**：サンプルはサンプルとして見せる
5. **早めに提案する**：新しい案件ほど、早く提案した人が選ばれやすい

## 応募する案件の選び方

✅ 応募してよい案件
- 1ページのホームページ、LP（縦長の1ページ）
- 文章・画像の差し替えなどの小さな修正
- HTML/CSSでの制作、または作り方の指定がない案件

❌ 最初は避ける案件
- WordPressでゼロから作る案件（慣れてから）
- ネットショップ、予約システム、会員登録などの機能を**自分でゼロから作る**案件
  - お金や個人情報を扱うので、不具合や情報流出が起きたときに責任を持てない
  - サーバーやデータベースの管理が、納品後もずっと必要になる
- 「納期3日以内」など、平日夜・土日では間に合わない案件
- 金額が極端に安い（作業量に対して1,000円など）案件

### ⭕ 専門のサービスを使う形なら対応できる

機能が必要な案件でも、すでにある専門のサービスを組み合わせれば、安全に対応できる。お金や個人情報は、そのサービスが管理してくれる。

| お客さんの要望 | 使うサービスの例 | 自分の仕事 |
|---|---|---|
| ネットショップがほしい | BASE、STORES、Shopify | ショップの開設と、ホームページからのリンク |
| 予約を受けたい | STORES予約、リザーブ、Googleフォーム | 予約ページの設定と、ホームページへのボタン設置 |
| 問い合わせを受けたい | Googleフォーム | フォームを作って、ホームページに埋め込む |

提案文では、例えば次のように書く。

```
ネットショップ機能は、BASE（無料で始められるネットショップ作成サービス）を使ってご用意し、ホームページからリンクする形をご提案します。お支払いや個人情報はBASEが安全に管理するため、安心してご利用いただけます。
```

- サービスの月額料金や決済手数料は、お客さんの負担になることを提案文に書いておく
- サービスのアカウントは**お客さん名義**で作ってもらう（自分の名義で作らない）
- 案件の依頼文に「WordPressで」「独自開発で」など作り方の指定がある場合は、この方法は使えないので応募しない

## 注意

- 提案文にメールアドレス・LINE・電話番号など、サイトの外で連絡を取る情報は書かない（規約違反になります）
- ポートフォリオのURLを載せてよいかは、各サイトのルールを確認する
