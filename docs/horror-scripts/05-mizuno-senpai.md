# 第5話「先輩は、入社前の私を知っていた」

**想定尺**：約6〜7分（本編のみ。エンディングCTAは別）
**今回は第1〜3話と同じ「実話怪談」の通常運用に戻す**（第4話だけ「実話の縛りなし」の特別回だった）

```
これは、転職して間もない頃に、実際にあった話です。

新しい会社に入って、最初についた先輩は、物腰の柔らかい、面倒見のいい人でした。
分からないことがあると、嫌な顔ひとつせず、丁寧に教えてくれました。
職場に慣れない私にとって、心強い存在でした。

ただ、少しだけ、気になることがありました。

雑談の中で、先輩が、私の過去について、驚くほど詳しいことがあったんです。

「昔、ピアノ、習ってましたよね」
「たしか、中学のとき、転校してきたんですよね」

聞いた覚えのない話まで、当たり前のように知っていました。
履歴書に書いた範囲を超えている気がして、少し引っかかりましたが、「詮索好きな人もいるものだ」くらいに思っていました。

ある日、先輩と昼休みに、たわいもない世間話をしていたときのことです。

「高校の文化祭で、劇の主役、やってましたよね」
「衣装、白いワンピースでしたよね」

背筋が、すっと冷たくなりました。
その話は、当時の同級生にしか、話したことがありませんでした。
SNSにも、書いたことはありませんでした。

「え、何で知ってるんですか」と聞くと、先輩は、少し笑って、こう言いました。

「昔から、知ってるので」

それ以上は、はぐらかされてしまいました。

それから、先輩のことが、少しずつ、気になるようになりました。

ある日、資料を借りに、先輩の机に行ったときのことです。
引き出しが、少しだけ開いていて、中に、古びた写真が見えました。

制服を着た、高校生くらいの、女の子が写っていました。

よく見ると、それは、私でした。

制服も、髪型も、当時の自分に、間違いありませんでした。
でも、その写真に、見覚えは、まったくありませんでした。
撮られたことすら、知りませんでした。

慌てて目をそらして、何も見なかったふりをしました。

その日から、先輩を、まともに見られなくなりました。

同期に、それとなく先輩のことを聞いてみると、意外な答えが返ってきました。

「水野さんって、前の部署でも、新人の女の子に、やたら詳しかったらしいよ」
「その子、結局、辞めちゃったんだって」

私だけではなかった。

怖くなって、人事に、それとなく相談してみました。
人事の人は、困ったような顔で、こう言いました。

「水野は、うちに来る前も、似たようなことが、あったみたいで」
「はっきりした証拠がないと、なかなか、動けなくて」

その言葉に、余計に、不安が募りました。

数日後、先輩が、休憩室で、私に声をかけてきました。

「最近、元気ないですね」
「何か、あったんですか」

心配してくれているような、優しい声でした。
でも、その目は、笑っていませんでした。

私は、そのまま、逃げるように、休憩室を出ました。

それから一週間後、私は、会社に理由をつけて、退職を決めました。
引っ越しもして、連絡先も、すべて変えました。

新しい職場は、快適でした。
誰も、私の過去を、詮索してくることは、ありませんでした。

数か月が過ぎた、ある日のことです。

新しく配属された先輩に、挨拶をしました。
穏やかそうな、物腰の柔らかい人でした。

自己紹介をすると、その人は、少し微笑んで、こう言いました。

「……久しぶりですね」

私たちは、初対面のはずでした。
```

**テロップ・演出メモ**
- 「昔から、知ってるので」「水野さんって、前の部署でも、新人の女の子に、やたら詳しかったらしいよ」「私だけではなかった。」「……久しぶりですね」の4か所は、強調演出（赤字・拡大・揺れ）が効きそう
- 先輩（水野さん）の台詞は基本的に青山龍星が読み、**ラストの一言「……久しぶりですね」だけ冥鳴ひまりに切り替える**。新しい職場の「別人のはずの先輩」が同じ声（＝同一の何か）だったと気づかせる演出。ここまでの3話とも違う「声の切り替え」の使い方として、シリーズの型に近づけた
- 同期・人事の台詞は青山龍星でよい（水野さん本人の声と区別できればOK）
- 机の引き出しに古い写真を見つける場面は、間（無音・BGMのフェードアウト）を長めに取ると効果的
- BGMは第1〜4話と同じ「夜の風の音」を流用予定。ただし今回はオフィスが舞台なので、休憩室・退職の場面だけ一瞬音を切る（無音にする）演出も検討

**投稿時のタイトル案**
- 「【実話】先輩は、入社前の私を知っていた」
- 「【人怖】転職先の先輩が、私の子供の頃を知っていた話」

**サムネイル文言案**
- 「その写真、いつ撮ったんですか。」
- 「初対面のはずなのに。」

**必要な背景写真（想定・約12枚）**
- オフィスのデスク・引き出し（開いている様子）
- 制服姿の学生の後ろ姿・シルエット（古い写真感のある質感が理想）
- 休憩室・給湯室
- オフィスの廊下
- 名刺・履歴書ふうの書類
- パソコン画面を見る手元
- 夜のオフィス街・退勤時の景色
- 引っ越しの段ボール
- 新しいオフィスの外観（対比になるもの）
- 名札・社員証ふうの小物
- 古びた写真そのもの（角が擦れた質感、演出用）
- 人事・相談窓口ふうのカット（任意）
