# 第3話「誰かが、まだ合鍵を持っている」

**想定尺**：約7分半（本編のみ。エンディングCTAは別）

```
これは、私が二年前に、一人暮らしを始めたときの話です。

就職を機に、実家から少し離れたくて、思い切って部屋を探すことにしました。
不動産屋さんに紹介されたのは、駅から少し離れた、築十五年ほどのアパートの一室でした。
相場よりだいぶ家賃が安くて、理由を聞いてみました。

「前の住人のかたが、家賃を滞納したまま、突然いなくなってしまって」
「それで、大家さんが早く決めたがってるんです」

少し引っかかりましたが、部屋自体はきれいにリフォームされていて、内見でも特に嫌な感じはしませんでした。
むしろ、日当たりもよくて、私はすぐに気に入ってしまいました。

契約して、荷物を運び込んで、新生活が始まりました。
引っ越して最初の一週間は、何も問題はありませんでした。

異変に気づいたのは、二泊三日の出張から帰ってきた夜のことです。
玄関の電気が、つけっぱなしになっていました。
自分では、確かに消して出かけたはずでした。
疲れていたし、記憶違いかもしれないと、そのときは気にしませんでした。

でも、それから、小さな違和感が続くようになったんです。

出しっぱなしにしていたゴミが、いつのまにか、まとめられている。
開けたままにしていた窓が、閉まっている。
脱ぎっぱなしだった洗濯物が、きれいにたたまれている。
玄関に脱いだ靴の、右と左が、いつのまにか逆に並べ直されていたこともありました。

最初は、自分が疲れて、無意識にやっているのかもしれないと思いました。
でも、それは決まって、私が二日以上、家を空けたときだけ起きることに気づいたんです。

夜、布団に入っていると、廊下から、かすかに足音が聞こえることもありました。
耳を澄ませても、それ以上は何も聞こえず、空耳だと思うようにしていました。

ある日は、冷蔵庫に入れていたはずのプリンが、ひとつだけなくなっていたこともあります。
食べた記憶なんて、ありませんでした。

友人にそれとなく話してみると、「気にしすぎだよ、疲れてるんじゃない？」と笑われました。
そう言われると、そうなのかもしれないと、自分に言い聞かせていました。

ちょうどその頃、夜遅くに帰ってきたとき、アパートの前に、知らない女の人が立っているのを見かけたことがありました。
会釈をしても、反応はなく、じっとこちらを見ているだけでした。
そのときは、道に迷った人だろうと思って、深く考えませんでした。

それでも気味が悪くて、玄関に、安い防犯カメラを取り付けることにしました。
数日後、また家を空けて帰ってくると、カメラの向きが、壁の方を向いていました。
録画データを確認しましたが、途中から、ただ壁だけが映り続けていました。

気になって、前の住人の名前を、SNSで検索してみたことがあります。
本人らしきアカウントは見つかりませんでしたが、婚約者らしき女性のアカウントが、今も更新され続けていました。
投稿には、いなくなったはずの前の住人に向けて、まるで今も一緒に暮らしているかのような言葉が、綴られていました。

さすがに耐えられなくなって、大家さんに相談することにしました。
大家さんは、少し言いにくそうに、こう言いました。

「実は、前の住人のかたに、合鍵をお返しいただいてないんです」
「連絡が取れなくなってしまって、鍵を交換する手続きも、後回しになっていて……」

その言葉を聞いて、背筋が冷たくなりました。
誰かが、私の知らないところで、この部屋に出入りしている。
しかも、その誰かは、掃除やゴミ出しまで、していく。
まるで、今でもここに住んでいるかのように。

大家さんに頼んで、すぐに鍵を交換してもらいました。
それから一週間ほどは、何も起きませんでした。
これで終わったと、私は少しずつ、安心し始めていました。

そんなある夜、お風呂から上がって、鏡の曇りを拭こうとしたときのことです。
鏡に、指でなぞったような文字が、うっすらと浮かび上がりました。

「おかえり」

自分が書いた覚えなんて、ありませんでした。
その夜は、一睡もできませんでした。
それでも、疲れがたまっていたせいかもしれないと、無理やり自分を納得させました。

一週間後の夜、友人の家に泊めてもらい、翌朝、家に帰ってきたときのことです。
玄関のドアに、鍵がかかっていませんでした。
鍵は、確かに交換したはずでした。

恐る恐る部屋に入ると、テーブルの上に、見覚えのないマグカップが置かれていました。
中には、まだ湯気の残る、お茶が入っていました。

誰かが、ついさっきまで、ここにいた。

私はその場で、警察に連絡しました。
駆けつけた警察官が調べても、鍵がこじ開けられた形跡はありませんでした。
まるで、正規の鍵を使って、堂々と入ってきたかのようでした。
警察の人には、「知り合いに合鍵を渡していませんか」と聞かれましたが、そんな人に、心当たりはありませんでした。

その後、大家さんが改めて調べてくれたところ、前の住人には、実は同居していた人がいたことが分かりました。
住民票には登録されていない、内縁の――前の住人の、婚約者だった女性です。

前の住人は、ある日突然、その女性を置いて、姿を消していたそうです。
女性は荷物も引き取らず、その後も、この部屋のどこかに、自分の居場所があると、思い込んでいるようでした。

大家さんは、力なく言いました。

「そのかた、まだ合鍵、持ってるかもしれません」

私はすぐに、そのアパートを出る決心をしました。

引っ越しの日、荷物を運び出している最中に、スマートフォンが鳴りました。
知らない番号でした。
出ると、女性らしき声で、こう言われました。

「どうして、勝手に出ていくの」
「ここは、私たちの部屋なのに」

私は、何も答えられずに、電話を切りました。
番号は、その場で着信拒否に設定しました。

新しい部屋に引っ越してから、半年が経ちました。
静かで、平和な毎日が続いています。

でも、たまに、仕事から帰ってくると、玄関の鍵が、ほんの少しだけ、回しにくく感じることがあります。

先月、近所のコンビニで、あの夜の声に似た女性を、見かけた気がしました。
目が合った気がして、すぐに顔をそらしてしまいました。
それから、その店には、行かないようにしています。

ただ、あの日の電話番号だけは、今でも、消せずにいます。
```

**テロップ・演出メモ**
- 「おかえり」（鏡の文字）、「そのかた、まだ合鍵、持ってるかもしれません」、大家さんの合鍵の話（初回の発覚）、ラストの電話の2行は、強調演出（赤字・拡大・揺れ）が効きそう
- 電話の声（「どうして、勝手に出ていくの」「ここは、私たちの部屋なのに」）は冥鳴ひまりの声にして、ラストで初めて「敵」の声が出てくる構成にする。それ以外（大家さんの台詞含む）は青山龍星が読む
- 鏡に「おかえり」と文字が浮かぶ場面は、曇った鏡の写真素材があると効果的
- BGMは第1・2話と同じ「夜の風の音」を流用予定

**投稿時のタイトル案**
- 「【実話】誰かが、まだ合鍵を持っている」
- 「【人怖】鍵を交換しても、部屋に入ってくる誰かがいた話」

**サムネイル文言案**
- 「その鍵、返してもらってません」
- 「鍵を変えても、入ってくる」

- 廊下
- キッチン・冷蔵庫
- 曇った浴室の鏡（「おかえり」の場面用、重要）
- テーブルとマグカップ
- 窓（開いている／閉まっている）

- 夜のコンビニ外観
