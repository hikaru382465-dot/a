# 第4話「いいねが、来るのが早すぎる」

**想定尺**：約7〜8分（本編のみ。エンディングCTAは別）
**今回は「実話」の縛りなし。SNS・デジタル系の人怖として、フィクションで構成**

```
これは、SNSにまつわる、少し奇妙な話です。

一人暮らしを始めてから、私は毎日のちょっとした出来事を、SNSに投稿するのが習慣になっていました。
フォロワーは、家族と、地元の友人が数人だけの、鍵アカウントです。
知らない人に見られる心配もないと思っていたので、気楽に続けていました。

異変に気づいたのは、半年ほど前のことです。
投稿すると、いつも同じアカウントから、真っ先に「いいね」がつくようになりました。

アカウント名は「shizuku_room」。
アイコンは設定されておらず、投稿はゼロ、フォローもゼロ。
フォロワー欄は非公開になっていて、何人にフォローされているのかも、分かりませんでした。

最初は、ただの偶然だと思っていました。
でも、投稿するたびに、必ず、数秒以内に「いいね」がつくんです。

昼でも、夜中でも、関係ありませんでした。

気になって、試しに、夜中の三時、誰も起きていないはずの時間を選んで投稿してみたことがあります。
結果は、同じでした。
投稿してから、五秒も経たないうちに、「いいね」がついていました。

友人に相談してみると、「ボットなんじゃない?」「通知だけ来るように設定してるだけじゃない?」と言われました。
そう言われると、少し安心しました。
きっと、そういう仕組みなんだろうと、自分に言い聞かせました。

そのとき、友人がふと、こんなことを言いました。

「そういえば、前に住んでたアパートでも、似たようなアカウントに、いつも一番乗りでいいねされてたことがあったな」
「引っ越したら、いつのまにか来なくなったけど」

軽い調子で言っていましたが、私は、あまり笑えませんでした。

それでも、何となく落ち着かなくて、shizuku_roomを、ブロックすることにしました。

ブロックした翌日から、おかしなことが続くようになりました。

ベランダに干していた洗濯物が、風もないのに、少しだけ、動いていることがありました。
夜、部屋の電気を消そうとすると、窓の外で、何かが動く気配がしました。
カーテンを開けても、誰もいません。
でも、視線のようなものだけが、いつまでも残っている気がしました。

ある夜、いつものように、部屋の中の写真を投稿しました。
本棚と、観葉植物が写った、何気ない一枚です。

数分後、鍵アカウントのはずの私に、知らないアカウントから、メッセージが届きました。

「その観葉植物、右にずらしたほうが、日当たりいいですよ」

血の気が引きました。
その日、私は、確かに観葉植物の位置を変えていました。
でも、それは、写真には写っていない場所でした。

つまり、その人は、写真に写っていないところまで、知っている。

すぐにブロックして、通報しました。
でも、それから数日後、また別の見知らぬアカウントから、似たようなメッセージが届くようになりました。

プロフィールには、ただ一言、こう書かれていました。

「いつも見てるよ」

アカウント名を変えて、消しては作り直し、何度でも、現れるんです。

耐えられなくなって、警察に相談しました。
警察の人は、「アカウントの持ち主を特定するのは難しい」と言いながらも、念のため、部屋の周りを調べてくれました。

そして、ベランダの外、隣の建物の非常階段から、ちょうど私の部屋の窓が見える場所に、たばこの吸い殻が、大量に落ちているのが見つかりました。

誰かが、そこから、ずっと私の部屋を見ていた。

SNSの「いいね」は、遠くから眺めているだけでは、あの速さにはならない。
通知が来た瞬間、その人は、本当に、窓の外にいたんです。

そう気づいてから、その部屋には、もう住めませんでした。

引っ越し先は、家族にしか、教えていません。
SNSのアカウントも、一度消して、新しく作り直しました。
フォロワーは、今度こそ、ゼロから始めました。

新しい部屋での、最初の投稿をした夜のことです。

通知が、ひとつ、届きました。

「shizuku_roomが、あなたをフォローしました」

アカウントを開くと、アイコンは、まだ、設定されていませんでした。
投稿も、フォローも、ゼロのままでした。

数秒後、私の投稿に、「いいね」がつきました。

友人が前に住んでいたアパートでも、同じことがあったと言っていたのを、私は、まだ思い出せずにいます。
```

**テロップ・演出メモ**
- 「その観葉植物、右にずらしたほうが、日当たりいいですよ」「いつも見てるよ」「shizuku_roomが、あなたをフォローしました」の3か所は、強調演出（赤字・拡大・揺れ）が効きそう
- DM・メッセージの台詞（観葉植物の一言、「いつも見てるよ」）は冥鳴ひまりの声にして、語り手（青山龍星）と別の「相手側の声」を明確に区別する。友人の台詞も含めて、それ以外は青山龍星が読む
- SNSの画面（いいね・通知・DM）はスマホ画面ふうのUIモックをテロップとして重ねると分かりやすい。文字だけのテロップでも成立する
- BGMは第1〜3話と同じ「夜の風の音」を流用予定。SNS通知音（軽い効果音）を「いいね」がつく瞬間に一度だけ入れると、テンポにメリハリが出そう

**投稿時のタイトル案**
- 「【人怖】いいねが、来るのが早すぎる」
- 「フォロワー0人のアカウントに、毎回一番にいいねされる話」

**サムネイル文言案**
- 「そのいいね、早すぎませんか。」
- 「フォロワー、ゼロのはずなのに。」

**必要な背景写真（想定・約13枚）**
- スマートフォンの画面を見つめる手元（夜）
- 一人暮らしの部屋（本棚・観葉植物が写るアングル）
- ベランダに干した洗濯物
- 夜のカーテン越しの窓（内側から）
- 隣の建物の非常階段（外観・遠景）
- たばこの吸い殻が落ちている足元
- 警察官・パトカー（任意）
- スマートフォンの通知画面ふうのカット（フォロー・いいねの演出用）
- 引っ越しの段ボール
- 新しい部屋の外観
- 夜の窓の外、人影のシルエット
- コンビニ夜景（任意、雰囲気用）
