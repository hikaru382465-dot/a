# 動画の作り方（VOICEVOX → Remotion）

1本目「引っ越し先の郵便受け」を例にした手順です。2本目以降も同じ流れで作れます。

動画の組み立て（テロップ・BGM合成・ズーム演出）は、ひかるが手作業でやるのではなく、**Claudeがこのセッションでffmpeg/Remotionを使って自動でやります**。ひかるがやるのは「1. VOICEVOXで音声を作る」までと、「3. YouTubeに投稿する」だけです。

## 1. VOICEVOXで音声を作る

1. 公式サイト（voicevox.hiroshiba.jp）からVOICEVOXをダウンロードしてインストールします（無料）
2. VOICEVOXを開き、メニューの「ファイル」→「テキスト読み込み」を選びます
3. `voicevox/01-yubinuke.txt` を選ぶと、1行ずつ読み込まれます
4. 左上でキャラクターを選びます。怪談なら、落ち着いた声が合います（例：「青山龍星」「No.7」「冥鳴ひまり」など。いくつか聞き比べて決めてください）
5. 右の「話速」を **0.9前後**、「間の長さ」を少し長めにすると、怖い話らしい、ゆっくりした読み方になります
6. 読み間違いがあれば、その行の読み（アクセント）を直します。人名の「佐野」などは特に確認してください
7. 「ファイル」→「音声を繋げて書き出し」で、1つの音声ファイル（wav）にします

### クレジット表記（必須）
VOICEVOXの音声を使った動画は、概要欄に次のように書く必要があります。キャラクターによって条件が違うので、使うキャラクターの利用規約を一度確認してください。

```
VOICEVOX:青山龍星
```

## 2. 動画に組み立てる（Claude担当）

ひかるがやること：
1. 手順1で書き出したwavファイルを、このセッションに送る
2. Pixabayなどから、暗めの背景写真を3〜5枚（夜の部屋、廊下、アパートの外観など、商用利用可のもの）保存して、同じくこのセッションに送る

あとはClaudeが以下をやります。
- 音声とテロップ（普段は白、決め台詞は赤字＋拡大＋揺れ）を合わせる
- 送ってもらった背景写真に、ゆっくり拡大する動き（Ken Burns風）を付ける
- BGM・効果音を、台本の「演出メモ」に合わせて挿入（音量はナレーションよりかなり小さく）
- 1080p・30fpsで書き出し

出来上がった動画はこのセッションから受け取れます。テロップのタイミングがずれている、演出が合っていないなど、直したい点があれば伝えてください。修正して作り直します。

### （保険）CapCutで手作業に切り替える場合

Remotionでの自動組み立てがうまくいかない場合は、以下の手順で手作業でも作れます。

1. CapCutで新しいプロジェクトを作り、**横長（16:9）** を選びます
2. 背景：暗い色の画像を1〜3枚入れます
3. 手順1で作った音声を読み込みます
4. 「テキスト」→「自動キャプション」で、音声からテロップを自動で作ります。読み間違いがないか確認します
5. BGMを入れて、音量をナレーションより**かなり小さく**（20〜30%程度）します
6. 台本の「演出メモ」にある場面で、BGMを止めたり、効果音を入れたりします
7. 背景画像が止まったままだと退屈なので、ゆっくり拡大する動き（キーフレーム）を付けると見やすくなります
8. 書き出し：1080p・30fps

## 3. YouTubeに投稿する

- タイトル・サムネイル文言は、各台本の最後にある案から選んでください
- 概要欄に、VOICEVOXのクレジットと、使ったBGM・効果音サイトのクレジットを書きます
- 最初は「限定公開」で一度見直してから、「公開」にすると安心です

## 動画の長さについて

今の台本は1本4〜5分です。慣れてきたら、1本の台本を長くするか、短い話を2つ合わせて8分以上にすると、動画の途中に広告を入れられるようになります。
