# 第6話「クローゼットの中に、誰かいる」

**想定尺**：約7〜8分（本編のみ。エンディングCTAは別）
**今回も「実話」の縛りなし**（ひかるの指示。「結構な怖さのあるものを」というリクエストなので、フィクションとして、これまでより直接的な恐怖・身の危険に寄せて構成した）

```
これは、一人暮らしを始めたばかりの、ある部屋で起きた話です。

新生活に慣れてきた、ある夜のことでした。
台所に置いていたはずのお菓子が、いつのまにか、減っていることに気づきました。

自分で食べた記憶はありませんでした。
数が合わないだけかもしれないと、そのときは、気にしないようにしました。

それから、小さな違和感が、いくつも重なるようになりました。

クローゼットの扉が、閉めたはずなのに、少しだけ開いていることがありました。
干しておいた洗濯物の位置が、微妙にずれていることもありました。
夜、眠っているとき、部屋の空気が、少しだけ動いた気がして、目を覚ますことが、何度かありました。

友人に相談すると、「気のせいだよ」「一人暮らし、慣れてないだけじゃない?」と笑われました。
そう言われると、そうなのかもしれないと、自分に言い聞かせました。

それでも、どうしても落ち着かなくて、安いネットワークカメラを、部屋の隅に、こっそり設置することにしました。
スマートフォンで、いつでも映像を確認できるタイプのものです。

数日間は、何も映りませんでした。
やっぱり気のせいだったのかと、少し安心し始めていました。

ある朝、目を覚まして、何気なくスマートフォンで、夜の映像を確認しました。

早送りで、流し見をしていたときです。

深夜二時過ぎ、クローゼットの扉が、ゆっくりと、開きました。

心臓が、跳ねました。

中から、人影が、出てきました。

その人影は、眠っている私の枕元まで、静かに歩いてきて――
しばらくの間、じっと、こちらを見下ろしていました。

そして、何ごともなかったかのように、また、クローゼットの中に、戻っていきました。

その夜だけでは、ありませんでした。
録画をさかのぼると、同じことが、何日も、繰り返されていました。

私は、その日のうちに、荷物もまとめず、部屋を飛び出しました。

警察に連絡し、立ち会いのもと、クローゼットを開けてもらいました。

奥の壁の一部が、外れるようになっていて、その先に、大人ひとりが、かがんでなら入れるくらいの、狭い空間が、隠されていました。

中には、ペットボトルの水と、簡易トイレ、それから、ノートが一冊、置かれていました。

ノートには、日付と時間、そして、私の一日の行動が、細かく記録されていました。

何時に起きて、何時に家を出て、何時に帰ってきて、何を食べて、いつ眠ったか。

その記録は、私がこの部屋に、引っ越してくる、前の日付から、始まっていました。

つまり、その人物は、私が引っ越してくる前から、この部屋の中に、隠れていたことになります。

警察が調べても、その人物の行方は、分かりませんでした。
壁の隙間は、外からも中からも、簡単に開け閉めできる作りに、改造されていました。

私は、二度と、その部屋には戻りませんでした。

新しい部屋を借りるとき、業者に頼んで、すべての壁を、念入りに、調べてもらいました。
異常は、見つかりませんでした。

それでも、夜、眠る前には、必ず、クローゼットの扉を確認する癖が、抜けません。

引っ越して、しばらく経った、ある夜のことです。

眠りに落ちる直前、部屋のどこかから、かすかに、声が聞こえた気がしました。

「……ただいま」

それが、空耳だったのか、そうでなかったのか、今でも、分かりません。
```

**テロップ・演出メモ**
- 「中から、人影が、出てきました。」「その記録は、私がこの部屋に、引っ越してくる、前の日付から、始まっていました。」「……ただいま」の3か所は、強調演出（赤字・拡大・揺れ）が最も効きそうな最重要ポイント
- カメラ映像を確認する場面は、テロップを「スマホ画面ふうの枠」で囲む、あるいは一瞬モノクロ・ノイズがかった質感にすると、映像の切り替わりが伝わりやすい
- ラストの「……ただいま」は冥鳴ひまりの声。これまでのシリーズ共通の「声の切り替えで正体を仄めかす」演出だが、今回は音量を編集時に落として「空耳かもしれない」余地を残す
  - VOICEVOX用テキストは、ひとまず通常の`himari`（ノーマルスタイル）で用意した。冥鳴ひまりに「囁き」スタイルがあれば（青山龍星の`aoyama_whisper`と同じ要領で）そちらの方がこの場面に合うと思うので、ひかるのVOICEVOXで確認できたら教えてほしい。あれば`himari_whisper`として`voicevox_batch.py`のSPEAKERSに追加する
- BGMは第1〜5話と同じ「夜の風の音」がベースだが、カメラ映像の場面だけ、BGMを一瞬止める（無音にする）と、より緊張感が出そう
- 効果音があれば、クローゼットの扉が開く「ギィ」という音が一番効果的（第4話用に探した通知音とは別に、扉の軋み音を探す価値あり）

**注意点（ひかるへの共有）**
- 今回は内容がこれまでより直接的（部屋に侵入して隠れ住んでいた、という身体的な恐怖）なので、投稿時のタイトル・サムネイルには「実話」を名乗らないほうが誠実だと思う。「フィクション」「創作」であることが伝わる文言にするのがおすすめ
- 内容的に、閲覧注意・怖さ強めであることが事前に伝わるタイトルにしておくと、期待値のミスマッチ（怖すぎるというクレーム等）を防げそう

**投稿時のタイトル案**
- 「【フィクション】クローゼットの中に、誰かいた話」
- 「【閲覧注意・創作】隠しカメラに映っていたもの」

**サムネイル文言案**
- 「クローゼットから、出てきた。」
- 「引っ越す前から、ここにいた。」

**必要な背景写真（想定・約12枚）**
- 一人暮らしの部屋全体（クローゼットが写り込む構図、重要）
- クローゼットの扉（閉まっている／少し開いている、2パターンあると理想）
- 台所・お菓子が置かれた棚
- 洗濯物
- ネットワークカメラ・スマートフォンでカメラ映像を見る手元
- 深夜の寝室（暗め）
- 警察官・パトカー（任意）
- 壁の隙間・隠し空間ふうのカット（暗くて狭い質感）
- ノート・手帳のクローズアップ
- ペットボトルの水（生活感のある小物）
- 引っ越しの段ボール
- 新しい部屋の壁（点検してもらった後、という設定のカット）
