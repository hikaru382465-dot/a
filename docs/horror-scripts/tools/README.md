# VOICEVOX自動音声化ツール

台本のテキストを1行ずつVOICEVOXに読み上げさせて、音声ファイルをまとめて作るツール。今まで「VOICEVOXを開いて1行ずつ読み込んで書き出す」という手作業だったのを自動化する。

## 最初の1回だけやること：Pythonのインストール

すでにPythonが入っていれば飛ばしてOK。

1. [python.org/downloads](https://www.python.org/downloads/) を開いて、Windows用のインストーラをダウンロード
2. インストーラを実行するときに、**「Add python.exe to PATH」に必ずチェックを入れる**
3. そのままインストールを進める

## 使い方（2回目以降はここだけ）

1. **VOICEVOXを起動しておく**（裏で音声合成の仕組みが立ち上がるまで数秒待つ）
2. Claudeが送ってきた台本テキストファイル（例：`03-xxxx.txt`）を、この`voicevox_batch.bat`の上にドラッグ＆ドロップする
3. 黒い画面（コマンドプロンプト）が開いて、1行ずつ処理が進んでいく
4. 終わると、同じフォルダに `台本名_audio.zip` というファイルができる
5. **そのZIPファイルをそのままチャットに送る**

これで、今までの「1行ずつ読み込んで書き出す」「文字化けしたファイル名を直す」作業が丸ごと不要になる。

## 台本テキストの形式

Claudeが用意する台本テキストは、こういう形式になる（1行1セリフ、`|`の前がキャラクター、後ろがセリフ）。

```
aoyama|これは、私が去年、一人暮らしを始めたときに体験した話です。
aoyama|社会人になって、初めて借りたアパート。
himari|「若い人が来てくれて安心だわ」
```

`|`がない行（セリフだけの行）は、自動的に語り手（青山龍星）の声になる。

## うまくいかないとき

- 「VOICEVOXに接続できませんでした」と出る → VOICEVOXを起動してから、もう一度ドラッグ＆ドロップしてやり直す
- 「不明なspeaker_key」「見つかりません」と出る → Claudeに伝えてくれれば、`voicevox_batch.py`の中の`SPEAKERS`の設定を直す
