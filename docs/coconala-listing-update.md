# ココナラ出品文：ホームページの修正・更新（2つ目のサービス）

最初の取引と評価を集めるための、安めのサービスです。

## 対応範囲の考え方

| サイトの種類 | 対応 | 理由 |
|---|---|---|
| HTMLで作られたサイト | ✅ | ファイルをもらえばClaude Codeで直せる |
| WordPress（文章・画像の差し替えだけ） | ✅ | 管理画面で入れ替えるだけなので初心者でもできる |
| Wix・ペライチ・Jimdoなど | ❌ 最初は受けない | サービスごとに操作が違うので、慣れてから広げる |
| デザインの変更、機能の追加 | ❌ | 差し替えより大きい作業なので、このサービスでは受けない |

**購入前に必ずサイトのURLを送ってもらい、対応できるか確認する。**

---

## カテゴリ

「ホームページの修正・更新」に近いカテゴリを選ぶ。選んだカテゴリの最低価格も確認する。

## サービスタイトル（25字以内・「ます」は自動）

```
ホームページの文章・画像を差し替え
```

## キャッチコピー（15〜30字）

```
今あるサイトの小さな修正を、お手頃価格で丁寧に対応
```

## サービス内容

```
ご覧いただきありがとうございます。ひかると申します。

「営業時間が変わったのに、ホームページが古いまま」
「メニューの値段を変えたいけど、やり方がわからない」
そんな、ホームページのちょっとした修正を代わりに行います。

■対応できる作業
・文章の書き換え（営業時間、料金、お知らせなど）
・画像の差し替え
・誤字や表示のずれなど、小さな修正

■対応しているサイト
・HTMLで作られたサイト
・WordPressで作られたサイト（文章・画像の差し替えのみ）

※Wix、ペライチ、Jimdoなどで作られたサイトは、現在対応していません。
※どちらで作られているか分からなくても大丈夫です。ご購入前にサイトのURLを送っていただければ、こちらで確認します。

■料金
基本料金で、5か所までの修正に対応します。

■対応できないこと
・デザインの大きな変更、ページの追加
・予約やお問い合わせフォームなどの機能の追加
```

## 購入にあたってのお願い

```
■ご購入前に、必ずメッセージで以下をお送りください
1. 修正したいサイトのURL
2. 修正したい内容（どこを、どのように変えたいか）

対応できるかを確認してから、ご購入いただく流れになります。

■WordPressのサイトの場合
管理画面に入る必要があります。お客様ご本人のパスワードはお伝えいただかず、作業用の編集者アカウントを新しく作ってお知らせください。作業が終わったら、そのアカウントは削除していただいて大丈夫です。作り方が分からない場合はご案内します。

■HTMLのサイトの場合
サイトのファイル一式をお送りいただくか、サーバーへの接続方法をご相談させてください。

■ご了承いただきたいこと
平日は会社員のため、ご返信・作業は主に平日夜と土日になります。
```
