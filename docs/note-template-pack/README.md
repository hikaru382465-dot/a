# 小さなお店のためのホームページテンプレート 5種セット

ご購入ありがとうございます。このセットには、次の5つのテンプレートが入っています。

| フォルダ | 業種 |
|---|---|
| cafe | カフェ・飲食店 |
| seitai | 整体院・治療院 |
| salon | 美容室・サロン |
| juku | 学習塾・教室 |
| reform | 工務店・リフォーム会社 |

それぞれの `index.html` を開くと、そのままブラウザでページが表示されます。

## できること・できないこと

- HTML/CSSだけで作られた、1ページのシンプルなサイトです
- お店の名前、住所、電話番号、文章はすべて仮の内容（サンプル）です。**必ずご自身のお店の内容に書き換えてご利用ください**
- 写真はフリー素材（Unsplash）へのリンクです。商用でお使いの際は、ご自身の写真や、商用利用可能な素材に差し替えることをおすすめします
- お問い合わせフォームや予約システムなどの機能は含まれていません。Googleフォームなどの外部サービスと組み合わせてご利用ください

## 編集のしかた

パソコンの「メモ帳」やコードエディタで `index.html` を開くと、文字で編集できます。プログラミングの知識がなくても、以下は書き換えやすいです。

- 店名・住所・電話番号・営業時間などの**文章**（そのまま日本語を書き換えるだけでOK）
- 色：ファイルの上のほうにある `:root { ... }` という部分に、色のコード（`#〇〇〇〇〇〇`）がまとまっています。ここを変えると、サイト全体の色が変わります
- 写真：`<img src="...">` の `"..."` の部分に、ご自身の写真のURLやファイル名を入れてください

**Claude CodeやChatGPTなどのAIに「このHTMLの、店名を◯◯に変えて」のように頼むと、簡単に書き換えられます。**

## 公開のしかた

作ったファイルは、以下のような方法で無料または安価に公開できます。

- GitHub Pages（無料）
- お名前.comなどのレンタルサーバー
