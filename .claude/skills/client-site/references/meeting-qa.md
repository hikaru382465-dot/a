# 打ち合わせで聞かれそうなこと・答え方

お客さんと話す（通話・対面）前に読む。金額や約束ごとは、出品文や他のメモと同じ内容にしてある。ここにない質問や、その場で決められないことは、無理に答えずに次の一言で持ち帰る。

> 「確認して、あらためてご連絡しますね」

その場で「できます」と言ったことは、後で取り消しにくい。迷ったら持ち帰る。

---

## 始めるときの一言

- 録音したいとき：「聞きもれがないように、メモ代わりに録音してもいいですか？」（断られたら、手書きのメモにする）
- 自己紹介：「ひかると申します。普段は会社員で、平日夜と土日にホームページを作っています」

---

## お金のこと

**Q. いくらですか？**
「1ページのホームページで、20,000円からです。写真やロゴをご用意いただけるか、ページの数、文章もおまかせいただくかで変わるので、今日お話を伺ってから正式な金額をお出ししますね」

目安（`docs/proposal-template.md` と同じ）
| 条件 | 目安 |
|---|---|
| 1ページ・フリー素材 | 20,000円 |
| 1ページ・写真やロゴあり | 25,000〜30,000円 |
| 3〜5ページ | 45,000〜60,000円 |
| 文章もおまかせ | 上に5,000〜10,000円 |
| セクションを1つ足す | 3,000円 |

その場で金額を言い切らず、「後で見積もりをお送りします」にしてよい。見積書は `billing.md` の手順で作れる。

**Q. 作った後、毎月お金はかかりますか？**
「1ページのシンプルなサイトなら、無料で公開できる場所を使えるので、サーバー代はかからない形にもできます。独自のアドレス（〇〇.com など）を使いたい場合は、その分の年間費用がかかります。どちらがいいか、一緒に決めましょう」

**Q. 支払いはどうすれば？**
- ココナラなどサイト経由のとき：「お支払いはココナラの中でお願いします」（サイトの外で払ってもらうのは規約違反になる）
- 知り合いなど直接のとき：「完成後に請求書をお送りしますので、お振込みでお願いします」

**Q. 領収書・請求書はもらえますか？**
「はい、お出しできます」（ココナラはココナラ側で領収書を出せる。インボイス対応を求められたら、その場で答えず持ち帰る）

## 期間・進め方

**Q. どれくらいでできますか？**
「写真や情報がそろってから、1週間ほどで一度見ていただける形にします」
（平日夜と土日の作業なので、余裕を持った日数を言う。短く言いすぎない）

**Q. どんな流れで進みますか？**
「今日お話を伺って → 最初の形を作ってスマホで見ていただいて → 直したいところを伺って → 完成、という流れです」

**Q. 何回まで直してもらえますか？**
「2回までは無料で直します。3回目からは1回3,000円です。気になるところは、まとめて言っていただけると助かります」

## できること・できないこと

**Q. 予約できるようにしたい／ネットで売りたい／問い合わせフォームがほしい**
「予約やお支払いは、専用のサービス（STORES予約、BASE、Googleフォームなど）を使って、ホームページからボタンでつなぐ形にしています。お金や個人情報は、そのサービスがしっかり管理してくれるので安心です」
- サービスのアカウントは、お店の名前で作ってもらう（ひかるさん名義で作らない）
- サービスの月額料金や手数料がかかる場合は、お店の負担になることも伝える

**Q. Instagramとつなげられますか？**
「はい、ホームページからInstagramへ飛べるボタンを付けられます」

**Q. 地図は載せられますか？**
「はい、Googleマップを載せて、そのまま道案内もできるようにします」

**Q. 検索で上の方に出るようにできますか？**
「検索の順位はGoogleが決めるので、お約束はできないんです。ただ、お店の名前で検索したときに見つけてもらいやすい作りにはします。あと、Googleマップにお店を登録（Googleビジネスプロフィール）しておくと、地図で探す人に見つけてもらいやすくなります」
（「1位にします」は絶対に言わない）

**Q. 自分で内容を変えられますか？**
「今回の作り方だと、ご自身で直すのは少し難しいです。営業時間やメニューが変わったときは、ご連絡いただければ差し替えます（5か所まで3,000円）」

**Q. 独自のアドレス（〇〇.com）はとってもらえますか？**
「アドレスはお店のものになるので、お店の名前で取っていただくのがおすすめです。取り方はご案内します」
（ひかるさん名義で取らない。やめたときにお店が困るため）

## 怪しい話になったとき

未経験歓迎を強く押す募集や、応募時に年齢・独立したいかを聞く募集は、話の途中で有料の勧誘に変わることがある。次の話が出たら、その場で断ってよい。

| 言われたこと | 返し方 |
|---|---|
| 講座・ツール・サポートなど、こちらがお金を払う話 | 「今回はお仕事として受けたいので、有料のものはお断りします」 |
| LINEなど、募集サイトの外でやりとりしよう | 「規約でできないので、サイトのメッセージでお願いします」 |
| 契約（仮払い）の前に作業を始めてほしい | 「仮払いしていただいてから始めます」 |

お店の名前・場所・オープン日を聞いても、はっきり答えない場合も注意する。

## こちらから聞くこと

`intake.md` の項目を聞く。最低限これだけは持ち帰る。

1. お店の名前
2. 住所
3. 営業時間・定休日
4. 電話番号など連絡方法
5. お店で一番伝えたいこと
6. 写真・ロゴがあるか、好きな色や雰囲気、Instagramなどのリンク

最後に「今日伺った内容をまとめて、あらためてお送りしますね」で締める。
