# 見た目の決め方

サイトを作るとき、色や書体を「なんとなく」決めない。お店の業種・雰囲気に合わせて、理由を持って決める。理由があると、お客さんに「なぜこの色にしたんですか？」と聞かれても説明できるし、他の出品者が作る「どこかで見たようなサイト」と差がつく。

## なぜここに気をつかうか

ホームページ制作の副業では、同じような構成(トップ→メニュー→アクセス)のサイトを何度も作ることになる。そのとき、色と書体を毎回同じパターンで済ませると、どのお客さんのサイトも似たような仕上がりになってしまう。お客さんは「うちの店らしさ」が出ているかどうかを見ているので、ここを手早く済ませると仕上がりの満足度に直結する。

## 決める順番

1. **このお店・お客さんは何屋さんで、誰に何を伝えたいか**を最初に一言でまとめる（例：「駅前の、初めてでも入りやすい整体院」）
2. その一言に合う**色**を3〜5色選ぶ。ヒアリングで「好きな色」を聞けていれば、それを軸にする
3. **書体**を1〜2種類選ぶ。見出し用と本文用を分けるかどうかも決める
4. **レイアウトの型**を決める（トップの見せ方、セクションの並び順、余白の取り方）

この4つを先に文章で書き出してから、コードを書き始める。作りながら決めると、途中で方向がぶれやすい。

## ありがちな「テンプレっぽさ」を避ける

以下は、AIにサイトを作らせたときによく出てくる、代わり映えのしないパターン。悪いわけではないが、**理由もなく毎回これになっている**なら見直す。

- 見出しの1単語だけ色や太字を変える
- ラベルをなんでも全部大文字にする
- 見出しの上に、意味のない小さなラベルを付ける（「ABOUT」「SERVICE」のような飾り）
- 内容が順番・手順でもないのに「01 / 02 / 03」と番号を振る（手順やステップなら問題ない。実際に今のサンプルでも「ご依頼の流れ」では正しく使っている）
- カードをどれも同じ角丸・同じ影で並べる
- ボタンの文字の最後に矢印（→）を付ける

これらは便利なので使ってもいいが、**「このお店だからこの見せ方にした」と説明できる**かどうかを基準にする。理由なく毎回同じパターンを使っているなら、別の見せ方も考える。

## 誰でも使えるかどうかの最低ライン

見た目の個性を出すより先に、ここだけは業種を問わず必ず満たす。お客さんのお店を訪れる人には、高齢の方やスマホの操作に慣れていない方も含まれるので、見た目が良くても押しにくい・読みにくいサイトは失敗になる。

- **文字の大きさ**：本文は16px以上を基準にする。小さい文字を「おしゃれさ」のために選ばない
- **行の高さ**：本文は行間を広め（1.5〜1.8倍程度）にとる。詰まっていると読みにくい
- **タップできる範囲**：電話番号やメニューのリンクなど、指で押す部分は44px四方くらいの余裕を持たせる。小さすぎるとスマホで押し間違える
- **色のコントラスト**：文字と背景の色の差をはっきりつける。薄いグレーの文字を薄いグレーの背景に乗せない。「おしゃれな配色」を優先して読みにくくしない
- **画像の読み込み**：画像を読み込む前後でレイアウトが大きくガクッと動かないようにする。`scripts/check_site.cjs` の横はみ出しチェックと合わせて、縦方向のガタつきも画面の画像で確認する
- **スマホでの操作優先**：お店のサイトを見る人の多くはスマホから来る。パソコンの見た目を先に作ってスマホは後回し、ではなく、スマホでどう見えるかを先に確認しながら作る

これらは`references/intake.md`のヒアリングとは別に、コードを書くときに毎回自分でチェックする項目。特別な指示がなくても、最低限として守る。

## 動きをつけるときの考え方

ページを開いたときのふわっとした演出や、カードにカーソルを乗せたときの動きは、入れすぎると逆にありきたりに見える。「ここぞ」という1か所（トップの見出しが出てくる、ボタンを押すと結果が変わる、など）に絞って使うほうが印象に残る。

## 仕上げの確認

コードを書き終えたら、`scripts/check_site.cjs` で機械的なチェックをするのとは別に、**保存されたスマホ・パソコンの画面画像を自分の目で見て**、次を確認する。

- 色や書体が、最初に決めた「お店らしさ」に合っているか
- 他に作ったサンプル・お客さんのサイトと、パッと見で見分けがつくか（似すぎていないか）
- 削れる飾りはないか。目立たせたい1か所以外は、思い切って地味にする

## 業種ごとのヒント

これまで作ったサンプルの傾向。同じ業種の依頼が来ても、同じ配色をそのまま使い回さず、その都度お店の雰囲気に合わせ直す。

| 業種 | これまでの方向性 | 気をつけること |
|---|---|---|
| カフェ・飲食 | 温かみのある色、写真を大きく見せる | お店ごとに「昭和レトロ」「北欧風」など雰囲気が全然違うことがあるので確認する |
| 美容室・サロン | 落ち着いた色、余白を広めに | 客層（若い人向けか、大人向けか）で色の選び方が変わる |
| 整体院・治療院 | 清潔感のある色、安心感を出す | 「痛くなさそう」「話しやすそう」など、伝えたい印象をヒアリングで確認する |
| 学習塾・教室 | 元気な色、保護者の不安に答える文章 | 対象年齢（小学生向けか高校生向けか）で雰囲気を変える |
| 工務店・リフォーム | 実直な色、施工事例の写真を活かす | 施工管理の経験があるので、実際の現場感が伝わる言葉を選べる。ここが強み |
