# お客さんへのメッセージ文

`【 】` を埋めて使う。どれもココナラやクラウドワークスのメッセージにそのまま貼れる形にしている。メールアドレス・LINE・電話番号など、サイトの外で連絡を取る情報は書かない。

## 制作を始めるとき

```
【お客様の名前】様

ご購入ありがとうございます。ひかるです。
いただいた内容をもとに、制作を始めさせていただきます。

【足りない情報があれば、ここで質問する】

途中の状態を【日付】ごろにご確認いただけるようにいたします。
平日は夜・土日の対応となりますが、よろしくお願いいたします。
```

## 確認のお願い（途中経過・初稿）

```
【お客様の名前】様

お待たせいたしました。ホームページの初稿ができましたので、ご確認をお願いいたします。

確認用のページはこちらです。
【確認用URL】
※確認用のため、検索には表示されない設定にしています。

スマホとパソコンの両方でご覧いただけます。
以下の点を特にご確認いただけますと幸いです。
・住所、電話番号、営業時間などに間違いがないか
・文章の内容や言い回し
・写真や色合いの雰囲気

【仮置きしている箇所があれば、ここで伝える。例：「写真は仮のフリー素材を使っています」】

修正は2回まで無料で承ります。気になる点を、まとめてお送りいただけますと助かります。
```

## 修正を反映したとき

```
【お客様の名前】様

ご指摘いただいた箇所を修正いたしました。
【確認用URL】

■修正した内容
1. 【修正内容】
2. 【修正内容】

今回が【1 / 2】回目の無料修正となります。
他に気になる点がなければ、このまま納品の準備に進めさせていただきます。
```

## 無料の修正回数を超えそうなとき

```
【お客様の名前】様

ご連絡ありがとうございます。
無料の修正は2回までとさせていただいており、今回のご依頼は3回目の修正となります。

恐れ入りますが、有料オプション「追加修正（1回 3,000円）」をご購入いただいたうえで、対応させていただけますでしょうか。
【まとめて1回で直せる内容なら、そう伝える】
```

## 納品のご連絡

```
【お客様の名前】様

最終版のホームページが完成しましたので、納品いたします。

■納品物
・ホームページのファイル一式（添付のzipファイル）

■公開について
【公開先についての案内。ひかるさんと相談して決めた方法を書く】

■ご確認のお願い
・スマホとパソコンの両方で表示をご確認ください
・電話番号のリンクを押すと、電話がかかることをご確認ください

今後、営業時間や料金の変更などがありましたら、修正・更新のサービスでも承っております。
このたびはご依頼いただき、ありがとうございました。
```

## 差し替えの完了のご連絡

```
【お客様の名前】様

ご依頼いただいた修正が完了いたしました。

■変更した内容
1. 【場所】：【変更前】→【変更後】
2. 【場所】：【変更前】→【変更後】

【HTMLの場合：修正したファイルを添付しています。 / WordPressの場合：作業が終わりましたので、作業用アカウントの削除をお願いいたします。】

表示をご確認いただき、問題がなければ取引の完了をお願いいたします。
ありがとうございました。
```
