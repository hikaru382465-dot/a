# ヒアリング項目

お客さんから届いた情報をこの表と照らし合わせ、足りないものを「お客さんに聞くことリスト」にする。

## 必ず必要なもの

| 項目 | 例 | ないとどうなるか |
|---|---|---|
| お店の名前 | 山田整骨院 | サイトが作れない |
| 業種 | 整骨院 | 構成が決められない |
| 住所 | ○○県○○市… | 地図とアクセスが作れない |
| 営業時間・定休日 | 9:00〜19:00、日曜休み | お客さんが来店できない |
| 電話番号など連絡方法 | 03-xxxx-xxxx、予約サイトのURL | 問い合わせにつながらない |
| 一番伝えたいこと | 「痛くない施術」「駅から近い」 | キャッチコピーが作れない |

## あるとよいもの

| 項目 | 例 |
|---|---|
| メニュー・料金 | 初回 3,300円 など |
| 写真 | 外観、店内、商品、スタッフ |
| ロゴ | 画像ファイル |
| 好きな色・雰囲気 | 落ち着いた緑、明るくポップ |
| 参考にしたいサイト | URL |
| SNS・予約サイト | Instagram、ホットペッパーのURL |
| 載せたい実績・お客様の声 | お客さんが書いてほしいと言ったものだけ |

## 情報が足りないときの質問文（コピペ用）

足りない項目だけを残して使う。一度に聞く数は多くても5つまでにする。多すぎると返事が遅くなる。

```
ご依頼ありがとうございます。制作を始めるにあたり、以下の内容を教えていただけますでしょうか。

1. 【足りない項目】
2. 【足りない項目】
3. 【足りない項目】

写真がお手元にない場合は、雰囲気に合うフリー素材の写真で仮に作成し、後から差し替えることもできます。
わかる範囲で大丈夫ですので、よろしくお願いいたします。
```

## 写真の受け取り方

- ココナラのメッセージにファイルを添付してもらう
- 写真の中に、お客さん以外の人の顔や、車のナンバーが写っていたら、載せてよいかをお客さんに確認する
- お客さんが撮った写真でも、他のサイトから保存した画像は使えないことがある。「ご自身で撮影された写真ですか？」と確認する
