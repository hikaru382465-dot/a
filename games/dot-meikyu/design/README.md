# 設計の表（Unity実装用・第1版）

数値はOpusが出した「たたき台」。遊んで調整する前提。決めごとの元は `../STATUS.md`（そちらが正）。

## ファイル
| ファイル | 中身 |
|---|---|
| enemies.csv | 敵とボス（森は数値つき、洞窟・沼は名前と役割だけ） |
| weapons.csv | 剣・弓・杖、レア度、おまけ効果、穴2つ |
| gems.csv | 宝石12種（最初は8種）、Lv1〜5、合成 |
| cards.csv | カード4種類（強化・スキル・変化・ペット）。進化つき |
| synergy.csv | タグを3枚・5枚そろえたときの効果 |
| jobs.csv | 魔法使い3種類（連射・範囲・召喚） |
| pet.csv | ペットの成長・進化・気絶・なかよし |
| run.csv | 1地域の進行（場所5か所＋ボス）、経験値、危険度、プレイヤーの基本値 |
| economy.csv | 魂・コイン、鍛冶屋の枝、商店、畑、料理、広告 |

## バランスの考え方
1. 場所1は、スライムが1〜2発で倒れ、遠くから撃つ敵が出ない。最初の1分では死なない。
2. 1地域は約10分（75＋90＋90＋100＋100秒＋ボス約90秒）。倒した数の条件で、うまい人はもっと早い。
3. 敵の体力は場所ごとに×1.0→×2.3。プレイヤーも約2〜3倍強くなり、それより少し先を行く。
4. ボスの前でLv13〜14、スキル3〜4つ、全体で毎秒100ダメージ前後。スライム王（体力4000）は60〜90秒で倒せる。
5. 武器は1回で2〜3本＋ボスの分。レジェンドは1%なので、ひろい屋のレア度+1が近道。
6. 宝石は1回で2〜3個。Lv5（Lv1が16個ぶん）は長く遊ぶ目標。
7. 魂はボスまで行くと約180、途中で死んでも約60。枝を全部とるのに約6800（ふつうで約40回）。
8. 魔法使いの専用スキルは60%。共通スキルも毎回1〜2枚は見られる。
9. ペットの成長点は1回で12〜18点。ボスの前に進化できるかが楽しみになる。
10. お金で強さは売らない。広告も課金も、時短か「その回だけ」の手助け。

## 数値を変えるときの注意
1. 敵の体力と攻撃は「基本値×場所の倍率×危険度の倍率」。まず場所の倍率で調整する。
2. 経験値の表と「倒した数の条件」は組。片方を変えたら、ボスの前のLv（目安13〜14）を確かめ直す。
3. 低い確率（1%・0.5%）と合成の個数は、遊ぶ長さを直接変える。小さく動かして、何回で手に入るかを計算してから決める。
