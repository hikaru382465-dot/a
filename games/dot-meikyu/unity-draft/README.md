# Unity用のC#の下書き（家のパソコンで、Unityに入れて使う）

Unity 6.6 では、まだ動かしていません（私は Unity が動かせない）。ただし、**Unityに依存しない部分は、このフォルダのテストで確かめ済み**です。

## 入れ方（金曜の夜に、家のパソコンで）
1. Unityのプロジェクトの `Assets/Scripts/` に、このフォルダの `Assets/Scripts/Core` と `Assets/Scripts/Unity` をコピー。
2. `design/` の `cards.csv`、`enemies.csv`、`gems.csv` を、`Assets/Data/` にコピー。
3. シーンに空のオブジェクトを作り、`GameData` 部品をつける。3つのCSVを、インスペクターにドラッグ。
4. 再生すると、コンソールに「データを読みこんだ：カード 58、敵 17、宝石 12」と出れば成功。

- Unityに依存しない部分（`Core`）と、Unityの部品（`Unity`）を分けてある。

### 入れ方
1. プレイヤーの絵のオブジェクト（SpriteRenderer つき）に `PlayerController` をつける。インスペクターの `Sprite` に、そのSpriteRendererを入れる。
2. **入力は、新しい Input System（Unity 6の標準）を使います。** エラーが出たら、Project Settings > Player > Active Input Handling が「Input System Package」か「Both」になっているか確認。
3. 再生して、PC：WASDで動く。スペースを押しながら動くと、左上のゲージがたまる。スペースを離すと、ため攻撃（満タンのとき）。
4. スマホ：画面のどこかを押して、指を動かす。ダッシュ：軽く2回たたく。

### 確かめ済み（Unity無しのテスト）と、これからUnityで確かめること
- 確かめ済み：スティックの向き・強さ・真ん中がついてくる／ため（3秒・止まるとたまらない・途中で離しても減らない・うった直後は動けない）／ダッシュ（3マス・待ち時間・長押しや歩きはタップに数えない）
- Unityで確かめる：実際の指の感じ（スティックの大きさ、遊び）、ため攻撃の出る気持ちよさ、ダッシュの出やすさ

### シーンの作り方（金曜の夜）
1. 地面（Plane）と、プレイヤーの絵のオブジェクト（SpriteRenderer）を置く。プレイヤーに `PlayerController`。
2. 空のオブジェクト `Game` を作り、`GameData`（CSV3つを入れる）と `SimRunner` をつける。
3. `SimRunner` に、`GameData`・プレイヤー・ペットの絵（Transform）・敵の絵のもと（Prefab。まず四角や丸でよい）を入れる。
4. 再生。敵が出て、自動で攻撃する。Console に、エラーが出ていないか見る。
5. 敵やダメージの見た目は、`SimRunner.SimEventRaised` を受け取る部品を作って、あとで足す。

### 確かめ済み（Unity無し・83項目すべてOK）：`sh tests/run_tests.sh`
- 武器：剣は、まわり1.6マスだけ／弓は、3体までつらぬく／杖は、4体に飛びうつり、1回ごとに-15%、2.5マスより遠くは飛ばない
- ため攻撃：剣×5・半径3.2／弓の扇の矢が何体でもつらぬく／杖は12回連鎖＋しびれ1秒
- 敵：弓兵の予告と矢／毒キノコの胞子と毒の雲／コウモリのジグザグ／スライム王の予告・弾12発・40%で小さな王2体に分裂・スライムを呼ぶ・倒すと小さな王も消える
- ひろい屋とペット：近いほうが先に取る／ひろい屋を倒すとレア度+1で返る／ペットは、弱い武器を食べ（成長点）、強い武器は倉庫へ／気絶8秒で復活／成長点15で進化
- 進行：場所1は、75秒か30体で出口が出て、出たあとは敵が増えない／場所が進むごとに敵の攻撃+10%
- 試走（カードなし）：弓・杖は、場所1を約33秒でHP満タンのままクリア。場所2はぎりぎり、場所3で倒れる（カードで強くなる前提のため、予想どおり）。剣は、ボットが逃げてばかりで、目安にならない

## 追加（攻撃の見せ方：なめらかさと手ごたえ）
- `FrameAnimator`：コマごとに長さを変えて絵を切りかえる。`clips` に、絵と `durations`（秒）と `hitFrame`（当たりのコマ）を入れる。ためを長く、振りを短く、当たりを少し長く。
- `HitFeedback`：会心・ダメージ・ボス撃破で、ヒットストップ（時間をほぼ止める）と画面の揺れ。`SimRunner` と カメラ を指定する。数字は小さめから。
- 見本：`assets/fx/smooth_demo.mp4`（左：全コマ同じ長さ／右：強弱つき）。目安の時間割は `art/make_smooth_demo.py`。
- 絵の中間コマが足せるときは「振り」の途中の2〜3枚が、いちばん効く。

## 追加（しろ光りと火花）
- `HitFlash`：当たった敵の絵を、一瞬（0.07秒）白ぬりにする。`Assets/Shaders/SpriteFlash.shader` でマテリアルを作り（Create > Material、Shader=DotMeikyu/SpriteFlash）、`flashMaterial` に入れる。
- `HitSparks`：当たった所に火花を散らす。ParticleSystem を1つ用意して（設定はスクリプトの上のコメント）、`sparks` に入れる。会心は黄色で多め。
- どちらも `SimRunner` を指定するだけ。`SimEvent.Target`（当たった敵）を、Core に足した。
- Unityでの見た目は、金曜に確認する（シェーダーは、URP用に書いたが、動かして確かめていない）。
