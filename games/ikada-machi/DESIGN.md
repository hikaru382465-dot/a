# イカダの海暮らし（仮）企画書

作成：2026-10-07（ひかると相談して決めた内容。名前は仮）

## ひとこと
海の天気と流れを読みながら、イカダを「海の上の小さな街」に育てる、ほのぼの拠点づくりゲーム。ゴールはなく、ずっと遊べる。

## 目的
- 収入（Steam＋スマホ）。1本目は小さく作って出し、反応を見て次に生かす。
- 絵は素材パックを買って使う（Claudeは絵が苦手なため）。Claudeはしくみと演出を作る。

## 決まったこと
| 項目 | 内容 |
|---|---|
| 視点 | 斜め見下ろし（約45度）の2D。画面の上に水平線と空を入れる |
| マスの大きさ | 64×32 ピクセルのひし形（2:1）。床の見本はひかるが別セッションで作成済み（木の板＋ロープ、3×2マス） |
| 舞台 | イカダの上だけ。島には降りない（島は遠くに見える背景） |
| 相棒 | コンピューター操作の相棒キャラ（1人でも遊べる）。2人プレイはあとでアップデート |
| ゴール | なし。小さな目標が続く「無限に遊べる」形 |
| 怪談 | 入れない |
| 独自性 | 住人が船で来て交渉／網のレベルで材料が増える／天気と海流を読む／景色を眺める |
| エンジン | Godot（Steam・スマホ両方に出せる。無料） |

## 1日の流れ
1. 朝：天気と海流を見る。網を広げる。
2. 昼：網にかかった物を整理して、イカダを広げる。
3. 夕方：船が来たら交渉する。
4. 夜：相棒とごはん、眠る。

## しくみ
### おなかとのどのかわき
- 時間で少しずつ減る。0になっても死なない（動きが遅くなり、画面が少しぼやける）。
- おなか：魚・果物・料理。のどのかわき：雨水・ろ過した水。
- 相棒が心配して食べ物を探してくれる。

### 天気と海流
- 晴れ（順調・のどが早くかわく）／凪（進まない・釣りと建築向き）／追い風（速く進む）／雨（雨水が集まる）／嵐（荷物が流される。屋根があれば守れる。網は引き上げる）。
- 船は天気が悪いと来ない。

### 網のレベル（材料の入手）
| Lv | 取れる物 |
|---|---|
| 1 | 木くず、ゴミ、小魚 |
| 2 | 縄、布、貝 |
| 3 | 粘土、石 |
| 4 | 鉄くず、ガラス |
| 5 | 設計図の箱、珍しい種 |
| 6〜 | 深い海ほど珍しい物（上がり続ける） |
- 強化には材料とお金（交渉で得た物）が必要。深く沈めるほど海流の影響を受ける。

### 船の住人と交渉
- 船が近づくと交渉画面が開く。住人は「欲しい物」と「渡せる物」を持つ。
- 成功すると仲間になってイカダに住む。断ると船は去り、別の日にまた来る。
- 住人が増えるとお店・設備が使える（パン屋、釣具屋、料理人…）。
- 絵は使い回し（色と旗を変えて見分ける）。会話は1人3〜4行。

### 景色を眺める
- イカダにベンチ・ハンモック・ブランコを置ける。座るとカメラが少し下がり、水平線を大きく映す。相棒も隣に来る。
- 朝・昼・夕・夜・雨・嵐のあと（にじ）など、時間と天気で景色が変わる。
- 眺めると「ほっとした」数値が上がり、相棒のしぐさ・住人の会話・贈り物が増える。
- 景色は図鑑に記録。写真モードで撮れる（SNSでの宣伝にもなる）。

## ゴールの代わり：小さな目標が続く
- 図鑑（魚・景色・網でかかった物・住人の好物）
- 住人ごとの小さなお願いと物語
- 季節の行事（春の花見・夏の海開き・秋の月見・冬の雪の夜）
- イカダの飾りと模様替え
- 網のレベルは上がり続ける
- 特別な出来事（例：網が深くなると、ときどき「貝のゆりかご」が引き上がり、赤ちゃんの動物が仲間になる）

## 作る範囲
### 最初の遊べる版（試作・2〜3か月）
- イカダの部品10種／住人3人／天気3つ（晴れ・凪・嵐）／網Lv1〜3／おなかとのどのかわき
### 最初に出す版（Steam・スマホ）
- 約5時間でイカダの基本が一通りそろう。そのあと図鑑・季節・住人の物語で数十時間。
- 価格の目安：600〜1,200円。
- 最初の2時間（Steamの返品の目安）で「ずっと遊べそう」と思わせる。
### アップデートで足す
- 新しい季節・住人・景色、2人プレイ、釣り大会など。

## 気をつけること
- Raft（有名作）に似すぎない。「サメ・脱出」ではなく「天気・交渉・景色・街づくり」で違いを出す。
- 終わりがないぶん、繰り返しに感じる時間が来る。図鑑と季節の行事で飽きを防ぐ。
- 図鑑・住人・行事は「データの表」にして、アップデートで足しやすくする。
- 素材パックは「斜め見下ろし（3/4 view / Isometric）」で角度をそろえる。

## 道具（今すぐ／あとでいい）
- 今すぐ：Godot 2D。素材パックを1つ先に決める（海・船・動物・イカダの部品）。
- 今すぐ：水の波紋と反射はシェーダー、時間帯の色は「環境」設定で。見た目の売りになる。
- あとでいい：写真モード、追い風・海流の細かい動き、2人プレイ、3D（Blender）は2作目で。

## 島マップ（HD-2D・確認用）
- 場所：`island/index.html`（ダブルクリックで開ける。three.js をネットから読む）。48×48マス（24×24のブロック4つぶん）、船着き場1つ（長さ10）、広場と井戸、小屋8軒、道、木・岩・草。「全体を見る」「広場へ」のボタンで見る場所を変えられる。
- HD-2D の作り：ドット絵の板（木・岩・ランタン）を3Dの地形・小屋・桟橋の中に置き、ブルーム・奥と手前のぼかし・色の調整・周辺の暗がりで仕上げる。朝・夕・夜を切り替えられる。
- パーツ分け（大きくなったら足していく形）：`common.js`（色・乱数）→ `map.js`（島の設計図データ）→ `camera.js` → `terrain.js` → `water.js` → `dock.js` → `houses.js` → `props.js` → `light.js`。パーツは互いに直接やり取りせず、`map.js` だけを読む。
- URLの最後に `?parts=camera,terrain,water` のように書くと、そのパーツだけで確認できる。`?low` で軽くなる。
- 本番（Godot）へは、`map.js` のデータ、マス 64×32、カメラ角度 30度、色の表を使い回す。three.js のコードそのものは組み直し。
- 使い道は未決定（「島には降りない」の方針との関係：住人の島の遠景／船で来る住人の出発地／別マップ、など）。

## 最小の試作（イカダ・ブラウザ版）
- 場所：`raft/index.html`（ダブルクリックで開ける。three.js をネットから読む）。
- できること：イカダの上を相棒（女の子）が歩く／海を押し続けてゲージをためる→離すと、その強さの距離へ網を投げる（向きは押した場所）／網が水の上で物をとる（とる時間は約4.5秒、いっぱいになると自動でもどる）／もどると持ち物に入る／食べる・飲む／床を足す（材料の木くずを使う）／網を強くする／昼夜と天気（晴れ・凪・嵐）／おなかとのどのかわき（0でも死なない。動きが遅くなり、画面がぼやける）。
- カメラ：始めはイカダに寄っていて、イカダが大きくなるほど自動で引く（`camera.js` の `goalFor`。0.25きざみで切り下げ。ホイールで少しだけ動かせる）。
- 流れてくる物は画面の左から右へ流れる。網は上流（左）へ投げるほど取れる。網のレベルより上の物は、見えるのに網を素通りする（上げたくなる仕掛け）。網のレベルが上がると、飛ぶ距離・とる広さ・入る数が増える（`data.js` の `NET_LV`）。嵐の間は網が投げられない。
- 作りの分け方：`data.js`（表）／`sim.js`（しくみ。THREE を使わない。Godot にはここを移す）／`camera.js`・`water.js`・`light.js`・`floor.js`・`buddy.js`・`drift.js`・`hud.js`。色は `island/common.js` を使い回し。
- URL：`?new`（保存を消して最初から）／`?fast`（時間10倍）／`?low`（軽く）／`?zoom=2`（ズーム固定）／`?parts=floor,water`（そのパーツだけ）。保存は自動（このブラウザの中）。
- まだ入れていない：船と交渉、住人、図鑑、景色を眺める、雨の見た目の細かさ、効果音。
- スマホで見る：`raft/make_artifact.py 出力先.html` で、部品を1枚にまとめた公開用のHTMLを作れる（Claudeの「アーティファクト」として公開する用）。スマホでは画面の細かさを1.5倍までに下げている。
- 持ち物（インベントリ）：画面の下に枠が並ぶ。先頭が道具（いまは「網」）、そのあとが材料・食べ物・飲み物。道具の枠を選ぶと手に持ち、持っている間だけ海を押して網を投げられる（もう一度選ぶとしまう）。食べ物・飲み物の枠をタップすると食べる・飲む。数字キー1〜9でも選べる。道具を足すときは `data.js` の `TOOLS` と、`state.tools` に足す。
- 網の絵：ひかるが描いた絵を `art/net/*.png`（throw_splash＝飛ぶ4コマ＋着水4コマ、idle＝水の上でゆれる4コマ、haul_a・haul_b＝引き上げ（試したが、いまは使っていない））に置き、`raft/make_net_art.py` を実行すると、1コマずつに切って `raft/net_art.js` に埋め込まれる（ロープは消し、プログラムで引く。絵の大きさは、網の広さ＝半径に合わせて自動で変わる）。絵を差し替えたら、`make_net_art.py` → `make_artifact.py` の順に実行する。
- 絵の細かさのルール：床は 1マス＝16ピクセル。網の絵は、網の幅が約100ピクセルあり、床より約3倍細かい（そのまま使っている）。そろえたいときは、網の幅を約30〜40ピクセルで描き直す。
- 引き上げ：網が出ている間に画面を押す／「網を引き寄せる」／いっぱいになる／時間切れ のとき、網が水の上を引きずられてイカダの端まで戻り、着いたら持ち物に入る（ひかるが「引きずるほうが、とれた感じがする」と選んだ）。引き上げ用の絵（haul）は、`net_art.js` に入っているが使っていない。
- 効果音：`raft/sound.js`。ブラウザの中で音を作る（音のファイルなし）。波の音（天気で大きさが変わる）、雨、網を投げる・着水・とれた・持ち物に入る・食べる・飲む・床を足す・網のレベルアップ・雷、網を引きずる音。画面を最初に触ったときから鳴る。右下の「音 ON/OFF」で切りかえ（設定は覚える）。本物の録音に差し替えるなら、候補は下の「音の候補」。
- 音の候補（OpenGameArt、いずれもCC0と書かれている。使う前に各ページでライセンスを確認する）：「40 CC0 water / splash / slime SFX」（rubberduck）、「6 short water splashes」（ezwa）、「sea and river wave sounds」（RandomMind）、「Beach Ocean Waves」（jasinski）。環境のネットワーク設定で、この場所からは opengameart.org などに接続できなかった（許可すれば、私が取ってきて入れられる）。
