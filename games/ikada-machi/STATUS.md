## 進行中・次にやること
- **海の見た目**：`water.js` のシェーダーに、イカダの映りこみ（`uRefl`で位置）・きらきら・大きなうねりを追加。キャラや置き物の映りこみはまだ（影だけ）。
- 粘土＝カタログの石を赤茶にぬった絵、鉄くず＝カタログのボルト（`make_objs.py`）。
- **水しぶきアニメ**：`art/items/splash.png`（20コマ）→ `raft/make_splash.py` → `splash_art.js`。前半10コマ＝大きいしぶき（釣りで使用）、15〜20コマ目＝弱い波紋（漂流物で使用）。網の着水はまだ網の絵のしぶきのまま。
- **釣りざおの絵**：`art/items/rod2.png`（ひかるの絵）から `make_objs.py` が切り出す。持っているだけの時は糸とウキつき、投げたあとは糸なし版＋ざおの先から水のウキへ糸。
- **釣りのリズム**：ウキがしずむと赤い輪がちぢむ。白い輪に重なる時（`data.js` ROD.great）にタップで「ナイス」＝2匹。数字は遊んで調整。
- **絵の差し替え済み**：木（丸太）・布・魚・床板・網・金づちはカタログ絵（`make_objs.py` の icons）。まだコードで描いた仮の絵：粘土・鉄くず。割れたヤシ・袋・カタログの木の実などは未使用。
- **釣りざお**：作業台で「釣りざお」（木4・縄2）を作る→手に持つ→海をタップで糸→ウキがしずんだらタップ（`data.js` の ROD、`sim.js` の castRod/reelRod）。魚が来る間隔・逃げる秒数は遊んで調整。
- **置き物の絵**：`raft/make_objs.py` で `art/items/catalog.png` から作業台・貯水槽（水の量4段階は色で表現）・ろ過器（布の枠＋しずく）を切り出し → `raft/objs_art.js`。ろ過器の絵は仮（もっと合う絵があれば差し替え）。
- **素材カタログ絵**：`art/items/catalog.png`（素材・食べ物・道具・服・家具・畑・イカダ・島・生き物・天気の約120個）。使える。背景がにじんでいるので、切り出しは `make_items.py` 方式で、必要な物から少しずつ。
- **漂流物の絵**：`art/items/sheet.png` から `raft/make_items.py` で切り出し → `raft/items.js`（縄・竿は `art/chars/sheet.png` から）。使用中：縄・石(2種)・布・ガラス(瓶)・ヤシの実。まだ使っていない絵：割れたヤシ・袋・竿（釣りざお用）。
- **やりたいこと（メモ済み）**：嵐のときの「網が破れる危険」と「珍しい物の追加」。くわしい案は `DESIGN.md` の「これからやること」に書いた。
- 作業台・貯水槽・ろ過器の絵は、コードで描いた仮のもの。ひかるのパレットで描き直したい。置く・飲む・ろ過の釣り合い（数字は `data.js`）は、遊んで決める。
- イカダの試作（`raft/index.html`）：できた。ひかるが遊んで、面白いか・つらい所を決める。次の候補：船と交渉、景色を眺める、相棒や物の絵をひかるのパレットで描き直す。
- 島マップ（`island/index.html`）：できた。次は、ひかるが見て直したい所を決める。木や小屋の絵は、いまはコードで描いた仮のもの。素材パックやひかるの絵に差し替える。
0. 決定：マスは 64×32 のひし形。ひかるが作った床の絵（3×2マス）はこの大きさ。1マス分に切り出して、3×3に並べてつなぎ目を確認する。
1. 素材パックを1つ決める（斜め見下ろし・海・船・動物・イカダの部品）。ひかるが買うか、Kenney / itch.io で探す。
