# 3D部屋（深夜の六畳）

ChatGPTの参考絵（`reference/` の6枚）をもとに、Blender 4.2 のPythonスクリプトで作った部屋。Godotで使う。

## できているもの
- 部屋の殻（床・壁・天井・窓・ドア・幅木）、机、引き出し、椅子、PC、モニター、キーボード、マウス、卓上ライト、マグカップ、スマホ、デジタル置き時計（2:17）、ペン立て、本、付箋3枚、ベッド（掛け布団・枕）、ラグ、ゴミ箱、小さな棚、本棚2つ、観葉植物、壁の写真2枚、カーテン（レースと厚手）、窓の外の夜の街
- 質感：床・壁・机・布団・ラグは、法線（凹凸）つきの絵。粗さの数値は `PLAN.md`
- 試し描き（夜・朝）：`blender -b -P blender/build_room.py -- --render 出力フォルダ [--morning]`

## 質感：Substance Painter風・すべてプロシージャル（第2版）
画像は使わず、ノードだけ。**汚しを1つのノードグループ（`SubstanceWear`）にまとめて、全材質に、強さを変えて重ねている**。
| 汚し | しくみ |
|---|---|
| エッジの塗装剥げ | Bevelノードで角を検出 → ノイズで欠けさせ、下地の色（むき出しの木・金属）を出す |
| 隙間の汚れ | AO（入り隅ほど黒い）＋砂粒のムラ |
| 上面の埃 | 法線のZ（上向き）でまだらに。隙間にもたまる |
| 床際の汚れ | 低い所ほど濃い（下から這い上がる）＋部屋の壁ぎわの床 |
| 垂れ跡 | Zだけを引き伸ばしたノイズ。縦の面に、高い所ほど濃く |
| 指紋 | ボロノイの細胞ごとに輪の模様。ざらつきを下げ、少し暗く |
- 下地の柄（板・壁・木目・キルト・毛足）もノードで作る。コードは `blender/wear_group.py`（汚しの本体）と `blender/materials_proc.py`（材質ごとの強さの表）。
- 段階：`--stage 1`＝汚しなし → `2`＝エッジ＋隙間 → `3`＝＋埃＋床際 → `4`＝＋垂れ跡＋指紋（最終）。
- 例外：光る画面の中身（モニターの壁紙、時計の数字、窓の外の街、壁の写真）は『絵』なので画像のまま。
- **Godotに持っていくとき**：プロシージャルのノードはglTFに入らない。そのため `export/room_night.glb` は、以前の画像の質感版（`--legacy`）のまま。汚しをGodotに持っていくには「焼き込み」（Blenderで質感を画像にする）が要る。→ 次の段階

## ファイル
| ファイル | 中身 |
|---|---|
| `export/room_night.glb` | Godot用（夜）。メッシュと質感。約12MB |
| `export/room.blend` | Blenderのファイル（画像の質感版） |
| `export/room_proc.blend` | Blenderのファイル（**プロシージャルの質感版**。Cyclesで描くと汚しが出る） |
| `textures/` | 質感の絵。`blender/textures.py` で作り直せる |
| `blender/build_room.py` | 部屋を作るスクリプト（これが本体） |
| `blender/check_glb.py` | 書き出した `.glb` の中身の点検 |

## Godotに入れるとき（注意）
1. `export/room_night.glb` と `textures/` を、Godotのプロジェクトに入れる。
2. **光は、Godot側で付け直す**。glTFは、面の光（area light）を運べないため、卓上ライトのスポットライトだけが入る。
   | 光 | 種類 | 位置（m） | 色 | 強さ | 役割 |
   |---|---|---|---|---|---|
   | 卓上ライト | SpotLight3D（入っている） | 机の上の卓上ライトの先 | 暖色 (1.0, 0.62, 0.30) | 強め | Key |
   | モニターの青 | OmniLight3D | (-0.80, 1.48, 0.97) | 青 (0.35, 0.5, 1.0) | 弱い | Fill |
   | 窓の月明かり | OmniLight3D か SpotLight3D | (-0.7, 2.4, 1.5)、室内（南）向き | 青 (0.3, 0.42, 1.0) | 弱い | Rim |
   | 全体のうす明かり | OmniLight3D | (0, 2.3, 0) | 青 (0.35, 0.45, 0.85) | とても弱い | 形が読める程度 |
3. 座標は、Blenderは `Z上`。glTF書き出しで `Y上` に変換されている（Godotでそのまま正しい向き）。
4. 朝にするとき：`textures/city_morning.png` を窓の外の面（`outside_city`）に差し替え、光を朝の色（暖色・強め）に、卓上ライトを消す。
5. 仕上げ（Godotのワールド設定）：Glow 0.4／SSAO 強め／霧 密度 0.02（青灰色）／彩度 0.85／コントラスト 1.1。

## 既知の弱い所（見直し候補）
- 絵（ChatGPT）に比べて、形が単純。本の背表紙、キーボードのキー、植物の葉は簡単な作り。
- 光は、Blenderの試し描き用。Godotで見え方が変わる。
- 椅子・布団・カーテンは、もう少し丸く、しわを増やせる。
