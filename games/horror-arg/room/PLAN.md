# 3D部屋（Blender → Godot）作成メモ

ChatGPTで作ってもらった参考絵（`reference/`）をもとに、Blenderで部屋を作る。Godotの `.glb` に書き出す。

## 参考絵の使い分け
| 絵 | 何に使うか |
|---|---|
| `02_topdown.png` | **配置の基準**（家具の位置・向き。いちばん信頼できる） |
| `03_desk_front.png` | 机の上の物と、机・椅子の形 |
| `04_bed_wide.png` | ベッド・窓・本棚・壁の飾りの形 |
| `05_night_morning.png` | 夜と朝の光（同じ部屋の2枚。窓まわりの比較） |
| `01_4angles.png` | 4方向の見え方（ドア・本棚の位置の確認） |
- 絵の中で家具の位置が少しずれている所は、`02_topdown` を優先する。

## 前提（確認してもらう）
- 六畳の洋室：約 2.7m × 3.6m、天井 2.4m（絵から見積もり。違えば直す）
- 窓：北の壁（机の上）。ドア：左（西）の壁。ベッド：右（東）の壁に頭を窓側。
- 床：濃い茶色のフローリング。壁：古びた白いクロス。

## 作るもの
部屋の殻（床・壁・天井・窓枠・ドア・幅木）／机／3段引き出し／椅子／PC本体（机の下）／モニター／キーボード／マウスとパッド／卓上ライト／マグカップ／スマホ／置き時計（デジタル）／ペン立て／本（数冊）／付箋3枚／本棚（机の左と右の奥）／ベッド（枠・マットレス・掛け布団・枕）／ラグ／ゴミ箱／カーテン（レースと厚手）／壁の写真2枚／照明スイッチ／観葉植物（本棚の上）

## 順番
1. 部屋の殻と大きさ → 2. 机まわり → 3. ベッド・本棚・小物 → 4. 質感 → 5. ライト（夜／朝）→ 6. `.glb` 書き出し → 7. Godotで確認

## 数値（ホラー向けの低照度）
- 光（3点）：Key＝卓上ライト（暖色 2700K、スポット、弱め）／Fill＝モニターの青い光（面光源、ごく弱い）／Rim＝窓の外の青い月明かり（窓から入る、青）
- PBR：床 roughness 0.25・normal 0.4／壁クロス roughness 0.9・normal 0.6／机の天板 roughness 0.35・normal 0.2／布団 roughness 0.95・normal 0.5
- ポストプロセス（Godot）：Glow 0.4／SSAO 強め／霧 密度 0.02（青灰色）／彩度 0.85／コントラスト 1.1／周辺減光 軽く
