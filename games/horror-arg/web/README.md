# 投稿受付中（試作）ブラウザ版

`index.html` をブラウザで開くと遊べる（サーバー不要）。`?reset` を付けると保存を消して最初から。

## スマホで遊ぶ
`python3 build_single.py 出力先.html` で、外部ファイルなしの1枚のHTMLができる。Claudeがこれをclaude.aiのページとして公開すると、スマホのブラウザ・Claudeアプリから遊べる（自分だけが開ける非公開ページ）。
スマホ幅では、窓は画面いっぱい・タップで開く・一覧と本文は切りかえ表示になる。

## ファイル
- `data.js`：文章（投稿16本・再投稿・前任者メモ・謎の答え・エンディング）。**直すのはここ**
- `game.js`：画面と動き ／ `sound.js`：効果音（数式で生成）／ `style.css`：見た目

## 段階1（できている）
ログイン → 起動演出 → 偽デスクトップ → 管理画面で承認／却下／保留 → 類似チェック（同じ言い回しの謎）→ 前任者メモへの追記 → 1日の終わり

## 段階2（できている）
- 1〜3日目に4本ずつ・4日目2本・終章（5日目）2本（計16本）。却下した投稿は翌日「再投稿」で戻る（最大2回、文が変わる）。保留は翌日に持ち越し
- 過去の投稿タブ、調査メモ（答えを書き込む）、最後の投稿者.txt（暗証番号 4417）、写真つき投稿（撮影日時が「明日」）
- 謎：①類似チェック ②投稿元コード→町の名前「はなみずき」 ③ログイン時刻 02:41 ④写真の撮影日時 ⑤暗証番号（IDの末尾）⑥16本の頭文字→合言葉
- エンディング：①閉鎖 ②承認（承認・却下の数で2種類の演出）③真相（合言葉）

## 段階3（できている）
- メール（1日目〜）：運営・投稿者・元管理人からのメール10通。未読の数がアイコンに出る
- 公開サイト（1日目〜）：承認した投稿が載る。承認の12〜18秒後に読者コメントの通知。承認した**翌日**から「いないはずの人」のコメントが増える
- さがす（2日目〜）：偽の検索サイト。検索語は `はなみずき`・`02:41`・`夜ばなし投稿館`・`八階`・`階段`・`仏壇`・`終電`・`留守電`・`公園`・`喫茶店`・`染み`・`管理人`・`たすけて` など。3日目から予測変換と履歴に打っていない言葉が出る。4日目から `新管理人` で「明日」の記事が出る
- **本文の下線の言葉**（2日目〜）：怪談の中の物・場所（八階・非常階段・仏壇・三番線・公園・喫茶店・染み・カメラ・撮影日時など）に下線が付き、押すと「さがす」が開く。どの怪談にも、はなみずき町の記事（3〜6年前の出来事）がつながっている。対応表は `data2.js` の `terms`
- **検索結果のページ**：記事の下に、閲覧数・「役に立った」「こわい」（押せる）・コメント欄・関連ページが付く。コメントは町民や怖い話まとめ掲示板の書き込み風。3日目からは、時刻が02:41の「（名前なし）」のコメントが混ざる（`data2.js` の `pageExtra`）
- ひとこと（3日目〜）：SNS風の呟き。プロフィールの登録時刻が全員「昨日 02:41」（ログイン時刻の手がかり）
- 文章は `data2.js`

## ギミック（できている）
9種類。いつから起きるかは `data.js` の `gimmicks`。`?nogimmick` で止まる。一覧は `../DESIGN.md` の最後。

## 開発用
- 開発者ツールで `checkHeads()`：書き出しの文字が合言葉と合っているか
- `__game.fire("clock")` ほか：ギミックを1つだけ起こす（clock / title / windowReturn / windowNudge / silentNotify）
- `__game.jump(N)`：N日目へ飛ぶ（全部承認して進める）
