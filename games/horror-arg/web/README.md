# 投稿受付中（試作）ブラウザ版

`index.html` をブラウザで開くと遊べる（サーバー不要）。`?reset` を付けると保存を消して最初から。

## ファイル
- `data.js`：文章（投稿16本・再投稿・前任者メモ・謎の答え・エンディング）。**直すのはここ**
- `game.js`：画面と動き ／ `sound.js`：効果音（数式で生成）／ `style.css`：見た目

## 段階1（できている）
ログイン → 起動演出 → 偽デスクトップ → 管理画面で承認／却下／保留 → 類似チェック（同じ言い回しの謎）→ 前任者メモへの追記 → 1日の終わり

## 段階2（できている）
- 1日目4本・2日目5本・3日目5本・終章2本（計16本）。却下した投稿は翌日「再投稿」で戻る（最大2回、文が変わる）。保留は翌日に持ち越し
- 過去の投稿タブ、調査メモ（答えを書き込む）、最後の投稿者.txt（暗証番号 4417）、写真つき投稿（撮影日時が「明日」）
- 謎：①類似チェック ②投稿元コード→町の名前「はなみずき」 ③ログイン時刻 02:41 ④写真の撮影日時 ⑤暗証番号（IDの末尾）⑥16本の頭文字→合言葉
- エンディング：①閉鎖 ②承認（承認・却下の数で2種類の演出）③真相（合言葉）

## 開発用
- 開発者ツールで `checkHeads()`：書き出しの文字が合言葉と合っているか
- `__game.jump(3)`：3日目へ飛ぶ（全部承認して進める）
