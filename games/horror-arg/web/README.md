# 投稿受付中（試作）ブラウザ版

`index.html` をブラウザで開くと遊べる（サーバー不要）。`?reset` を付けると保存を消して最初から。

## ファイル
- `data.js`：文章（投稿・前任者メモ・謎の印）。**直すのはここ**
- `game.js`：画面と動き ／ `sound.js`：効果音（数式で生成）／ `style.css`：見た目

## 段階1（できている）
ログイン → 起動演出 → 偽デスクトップ（ウィンドウ移動・最小化・タスクバー・時計）→ 管理画面で1日目の4本を承認／却下／保留 → 類似チェック（同じ言い回しを探す謎）→ 前任者メモに追記 → 1日の終わり画面

## 次の段階
2: 2日目〜終章・エンディング分岐・謎（投稿元の数字・時刻・ゴミ箱の写真）／3: メール・SNS・コメント・偽の検索サイト／4: 外のサイト・隠し文字つき写真・効果音の追加／5: 見直し
