# ホラーARGゲーム（仮）企画書

Steamで販売する、ゲームの外までつながるホラー。1人・低予算で作る。

## 方針
- エンジン：**Godot 4**（場面もコードも文字ファイル→Claudeが全部書ける／無料／軽い／イカダ町と知識を共有）。Steam連携は GodotSteam。
- 作りは「偽のデスクトップ」。2DとUI中心なのでUnrealの見た目の強さは不要。
- 1本目は小さく：遊ぶ時間**約1時間**（隠し要素込みで1時間15分まで）、価格500〜800円、日本語＋英語。

## MVPの範囲
- 偽のデスクトップ1つ、アプリ5つ（メール・写真・文書・ゲーム内ブラウザ・カレンダー）
- 3章＋エンディング1つ＋隠しエンディング1つ
- ゲームの外：外部サイト1つ（隠しページ3つ）／ファイル書き出し2〜3か所／時間で起きる出来事1つ
- **外部サイトが止まってもゲーム内だけで最後まで遊べる**（外部は「おまけの真相」）

## コンセプト案（ひかるが1つ選ぶ）
- **A「遺品のノートPC」（推し）**：亡くなった人のノートPCを調べる。日記・写真・予定表に「いないはずの人」が毎日少しずつ写り込む。外にはその人が関わっていた架空の団体のサイト。仕事や現場には縛られない。
- B「留守電」：中古の留守番電話のデータを再生。メッセージが現実の日付で増える。公衆電話の世界観とつながる。
- C「心霊スポット巡りブログ」（**保留**：ホラーゲームを何本かリリースしてから作る。ひかる希望）：更新が止まったブログの管理画面に入り、書いた人の最後の行き先を追う。

## ARGの仕掛け一覧
| 仕掛け | 注意 |
|---|---|
| 架空のWebサイト（静的・無料置き場＋独自ドメイン） | ドメイン代を毎年払い続ける。Whois代行で住所を隠す |
| セーブ用フォルダにファイル書き出し | そのフォルダの外は触らない・消さない・隠さない |
| 現実の時計（夜0時以降／発売○日後） | 時計を変えるズルは許す前提 |
| 登場人物のSNS・ブログ更新 | 個人情報を集めない（集めるならプライバシーポリシー） |
| ストア画像の隠し文字・QR | 外部リンクの制限をSteamworksで確認 |

## やってはいけないこと
- ウイルスに見える動き、本物のエラー画面・Steam/Windows画面のそっくりコピー、勝手な通信
- 実在の会社名・団体名・電話番号・地名との重なり。本物の個人の写真・資料は使わない

# 決定案：F「怪談投稿サイトの管理人」（仮題「投稿受付中」）

Steamで似たゲームがないことをひかるが確認済み（2026-10-15）。コンセプトA〜Eより上の内容を優先する。

## 一行で
怪談投稿サイトの新しい管理人になった主人公が、毎晩届く投稿を「承認／却下」していくうちに、投稿がぜんぶ同じ人の書いたもので、しかも自分のことを書いていると気づく。

## 遊びの流れ（1日 = 1章、全3章＋終章）
1. 夜、管理画面を開く。未審査の投稿が3〜5本たまっている。
2. 1本ずつ読んで「承認」「却下」「保留（前任者のメモを見る）」を選ぶ。
3. 読む材料：本文／投稿者ID・投稿時刻・投稿元の情報／前任者の引き継ぎメモ／過去の承認済み投稿。
4. 気づきが謎になる：投稿者名は別々なのに、言い回し・誤字のクセ・時刻が同じ。IDの数字を並べると意味が出る。
5. 承認した投稿は外のサイトに実際に載る（ARG）。却下した投稿は、翌日また形を変えて届く。
6. 章の終わりに、前日の選択で本文が変わった投稿が届き、だんだん主人公の部屋・名前・今日の行動に近づく。

## 画面（偽のデスクトップ）
管理画面／メール（運営からの連絡、投稿者からの苦情）／メモ帳（前任者の引き継ぎ）／ブラウザ（公開サイト）／ゴミ箱（却下した投稿。夜に勝手に増える）

## 時間配分（目標：1周約1時間）
| 章 | 投稿数 | 時間 |
|---|---|---|
| 1日目 | 4本 | 約12分 |
| 2日目 | 5本 | 約17分 |
| 3日目 | 4本 | 約17分 |
| 終章 | 2本＋選択 | 約14分 |
- 隠しエンディングは、外のサイトを解く分で＋10〜15分（本編の長さには入れない）。
- 長くなりすぎたら、2日目の1本を削る。

## 章立て（案）
| 章 | 内容 | 怖さの芯 |
|---|---|---|
| 1日目 | ふつうの怪談が並ぶ。1本だけ、書き方が前任者のメモと同じ | 「同じ人？」の違和感 |
| 2日目 | 投稿が主人公の街・駅・時間帯に寄ってくる。却下したのに戻ってくる | 逃げられない感じ |
| 3日目 | 投稿の内容が「いま主人公がしたこと」になる（承認ボタンを押した、など） | 見られている |
| 終章 | 最後の1本の投稿者欄に主人公の名前。承認か却下か | 選択がエンディングを分ける |

エンディング：①却下しつづける（サイト閉鎖）／②承認する（自分も怪談になる）／③隠し：ARGの鍵を解いて投稿者の正体にたどり着く

## ARGの仕掛け（外のサイト）
- 公開サイト「（架空の名前）」を実際に公開：承認した投稿が読める。ゲームを進めるほど本当に更新される。
- 投稿IDを並べるとURLの一部になり、隠しページ（前任者の最後の投稿）が開く。
- セーブ用フォルダに「承認待ち.txt」が増える（中身は主人公宛ての短い怪談）。
- 夜0時以降に起動すると、1本だけ追加の投稿が届く（現実の時計）。
- サイトが止まってもゲーム内だけで全エンディングまで遊べる。外は「真相のおまけ」。

## ひかるの強みの使いどころ
- 怪談の本文は「実話怪談ラジオ」の台本の書き方でそのまま使える。1本200〜400字。本編は16本で約1時間（読む・調べる1本2分×16＝約32分、画面操作・演出・メモ・ゴミ箱の気づきで約28分）。
- 声は不要。文章と効果音（Freesound）だけで成立する。

## 最初の30秒（下書き）
1. 真っ暗な画面。キーボードの音。「ログインしました。前任の管理人は退会済みです」
2. 管理画面。未審査の投稿が「4」。通知音が1回。
3. 1本目を開く：エレベーターの怪談。ふつうに怖い。承認すると「公開しました」。
4. 2本目の本文の末尾が、前任者メモの最後の1行と同じ言葉で終わっている。
5. 投稿者名は別人。IDの末尾は同じ。メモ帳が勝手に1行ふえる：「みつけた？」

## 謎解き・解読（追加・2026-10-15）
方針：**解けなくても通常エンディングまで進める**（詰まり防止）。解くと「気づき」が増え、隠しエンディングの鍵になる。1つ約2〜3分で、本編1時間の中に入れる。

| 章 | 謎 | やること | 答え・ごほうび |
|---|---|---|---|
| 1日目 | 言い回し比べ | 管理画面の「類似チェック」で2本の文を並べ、同じ言い回しを選ぶ | 「同じ人が書いている」と確定。前任者メモの1行が開く |
| 2日目 | 投稿元の数字 | 投稿元情報の数字を、前任者メモの対応表（A→1…）で読みかえる | 主人公の街の名前になる。投稿が主人公に寄ってきた理由がわかる |
| 2日目 | 投稿時刻 | 全投稿の時刻を並べると、毎回3分ずつ主人公のログイン時刻に近づく | 「見られている」の確信。却下の意味が変わる |
| 3日目 | ゴミ箱の画像 | 却下した投稿に添えられた写真の撮影日・ファイル名を見る | 撮影日が「明日」になっている。次の投稿の予告 |
| 終章 | 前任者のロックメモ | 合言葉は、前任者が却下理由欄に残した数字4つを順に並べたもの | 前任者の最後のメモ。エンディング①②の補足が読める |
| 隠し | 頭文字読み | 16本の書き出しの1文字を順に並べる（本の順は固定） | 外のサイトの合言葉。隠しエンディングの入口 |

- 頭文字読みは、却下で戻ってくる版でも書き出しの文字を変えない。
- ヒントは3段階：メモ帳の一行→画面の小さな違和感→合言葉入力欄に「あと○文字」と表示。
- 試作で友達に解かせて、30秒で解ける謎は削るか難しくする。

## エンディング分岐（追加・2026-10-15）
- 承認した本が多いほど②の結末が重い（承認した怪談が主人公の部屋で起き始める）。
- 却下した本が多いほど①の結末が不気味（却下した本が最後に全部戻ってくる）。
- 結末の画面は共通で、最後の演出だけ変える。

## 調べ物：偽の検索サイト（追加・2026-10-15）
- ゲーム内ブラウザに、**架空の名前の検索サイト**（仮「さがす」）を置く。本物のGoogleなどのロゴ・画面・名前はそっくりにしない（規約とトラブルを避ける）。
- 仕組み：検索ワードの辞書（約40語）。入力した言葉に合う結果ページが出る。辞書にない言葉は「該当なし」。
- 調べるきっかけ：投稿の中の地名・人名・店名・日付、前任者メモの単語。
- 結果ページの例：地元の古い掲示板、閉店した店の紹介、前任者の昔の投稿、主人公の街のニュース。
- 怖い仕掛け：
  - 検索履歴に、自分が打っていない言葉が増える
  - 予測変換（サジェスト）に、まだ打っていない言葉が出る
  - 3日目、「自分の名前」で検索すると、まだ起きていない出来事の記事が出る
- 謎解きとの接続：2日目の街の名前で検索 → 前任者が最後に調べた場所がわかる、など。調べ物の答えはメモ帳に自動で書き写される（メモを取らなくていい）。
- 時間：1回の調べ物は約2分。本編の1時間の中で、投稿を読む時間と置き換える（16本のうち3〜4本は調べ物つきにする）。
- 作りやすさ：辞書は表（CSV）で作れる。Claudeが入れ物を作り、ひかるは言葉と結果の文章を書く。
