# 3Dホラーゲーム「公衆電話」 状況メモ

最終更新：2026-10-03（第8版：Unreal 5.3.2 で電話ボックスの取り込み成功。夜の見た目まで確認）

## ゲームの設定（ひかるが決めたこと）

- 主人公：心霊スポット巡りが趣味の大学生
- 舞台：森の中にぽつんとある公衆電話（マップは大きくしない）
- 流れ：森の道を進む → 途中の掲示板で昔の新聞（ここで何があったか）を読む → 公衆電話に入る → 扉が閉まって開かなくなる → 手がかりを使って扉を開けて脱出
- 演出：ボックス内のライトが点滅・消灯／明るくなるとガラスに怖い張り紙がふえている（さっきは何もなかった）／幽霊が少しずつ近づく／外からのぞいてくる

## 今できていること

- ファイル：`games/koushu-denwa/index.html`（これ1枚で動く。3Dの部品をネットから読み込む）
- 森の道、入口の看板、掲示板（提灯が目印・新聞の切り抜きが読める）、奥の公衆電話ボックス
- ボックスに入ると扉が閉まり、内側から出られない
- 5〜13秒ごとに「ちらつく→真っ暗→点灯」。点灯のたびに張り紙がふえ、幽霊が近づく
  - 1回目：道の奥に立つ／2回目：もっと近く／3回目：ボックスの横／4回目：ガラスの外からのぞく／5回目：目の前に出て終わり（ゲームオーバー）
- 謎解き：新聞の日付（7月14日）→ 張り紙「あの日をおして（4けた）」→ 電話で **0714** を押す → 扉が開く → 外に出ると脱出成功
- まちがえた番号を押すと、次の怖い演出が早く来る
- 操作：WASD、マウス、E（調べる）、F（ライト）、Shift（走る）。スマホは画面の左右をなぞる＋「調べる」ボタン

## Blenderの電話ボックス（第5版：実物の写真に合わせた）

- ひかるが送ってくれた3枚の写真（夜の公園・道路・街中のNTTの新しいタイプ）を見本にした
- 作成スクリプト：`games/koushu-denwa/blender/make_phonebooth.py`（Blenderの「Scripting」タブで開いて▶を押すと、電話ボックスができて `assets/phonebooth.glb` に書き出される）
- 見本に合わせた点：黒っぽいブロンズ色のアルミ枠、中央に縦の枠があるガラスのドア（ステンレスの引き手つき）、天井の蛍光灯2本、蛍光グリーンのデジタル電話機（液晶・12個のボタン・カード口・硬貨口・受話器・金属コード）、灰色の柱、青い料金案内板、右側の台と電話帳、足のせ、鉄の台座、屋根のアンテナ
- 大きさは幅・奥行き1.25m（本物は約1m。ゲームで動けるよう少し広め）
- ゲームは `assets/phonebooth.glb.js`（文字にした版）を読み込む。読み込めないときは、手作りの箱の電話ボックスが出る
- ボックスの中は近いので、懐中電灯とボックスの明かりを弱めてある（ボックスの外では今まで通り）
- モデルを変えたら、スクリプトを実行し直して `phonebooth.glb` と `phonebooth.glb.js` の両方をコミットする
- 確認用の絵：`assets/phonebooth_preview.png`
- まだ見本と違うところ：ドアは実物のような「折りたたみ」ではなく、1枚で開く動き／雨のしずくや貼り紙の跡はなし／外の台座まわりの草や汚れはまだ
