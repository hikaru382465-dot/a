# 3Dホラーゲーム「公衆電話」 状況メモ

最終更新：2026-10-04（第13版：ゲームの謎解き設計と、紙もの・看板・液晶の画像を追加）

## ゲームの設定（ひかるが決めたこと）

- 主人公：心霊スポット巡りが趣味の大学生
- 舞台：森の中にぽつんとある公衆電話（マップは大きくしない）
- 流れ：森の道を進む → 途中の掲示板で昔の新聞（ここで何があったか）を読む → 公衆電話に入る → 扉が閉まって開かなくなる → 手がかりを使って扉を開けて脱出
- 演出：ボックス内のライトが点滅・消灯／明るくなるとガラスに怖い張り紙がふえている（さっきは何もなかった）／幽霊が少しずつ近づく／外からのぞいてくる

## 今できていること

- ファイル：`games/koushu-denwa/index.html`（これ1枚で動く。3Dの部品をネットから読み込む）
- 森の道、入口の看板、掲示板（提灯が目印・新聞の切り抜きが読める）、奥の公衆電話ボックス
- ボックスに入ると扉が閉まり、内側から出られない
- 5〜13秒ごとに「ちらつく→真っ暗→点灯」。点灯のたびに張り紙がふえ、幽霊が近づく
  - 1回目：道の奥に立つ／2回目：もっと近く／3回目：ボックスの横／4回目：ガラスの外からのぞく／5回目：目の前に出て終わり（ゲームオーバー）

## 凹凸の追加（第11版）

- ひかるの指摘：「ガラス以外が全体的にのっぺりしている」。原因＝色と粗さだけで、凹凸（ノーマルマップ）がなかった
- 追加した凹凸：`phone_body_normal`（オレンジの皮のような細かい凹凸・さびの穴・傷）、`bronze_normal`（腐食の粉は盛り上がり、さびは穴）、`gray_paint_normal`（塗装はがれはへこみ・ふちは盛り上がり）、`ceiling_normal`、`floor_normal`（コンクリートの穴・落ち葉・ひび）
- Unrealのスクリプトは、凹凸画像を読み込むとき「緑チャンネル反転」をオンにする（Blenderの向きとUnrealの向きの違いを直すため）
- 強さは弱めにしてある（強すぎると、枠や柱にしま模様が出る）。強弱は `make_textures.py` の `normal_from_height(…, 数字)` の数字で変える
- 光のコントラスト（Key/Fill/Rim の3点照明）は、次に調整する
