# 3Dホラーゲーム「公衆電話」 状況メモ

最終更新：2026-09-30

## 現状

- 3Dマップ第1版ができた：`games/koushu-denwa/index.html`（これ1枚で動く。three.jsをネットから読み込む）
- 中身：夜の道路、ちらつく緑の公衆電話ボックス、切れかけの街灯、自販機、バス停、閉まった商店、木、月と星
- 操作：WASD＋マウス、Fでライト、Shiftで走る（スマホは画面の左右をなぞる）
- 幽霊：ときどき道路の奥・ガードレール・電話ボックスの中に現れ、ゆっくり近づいて消える。環境音（風・低い唸り）あり
- 壁・建物・電話ボックスには通り抜けられない当たり判定あり

## 進行中・次にやること

1. ひかるが実際に遊んで、怖さ・暗さ・広さの感想を教えてくれる（ここから調整）
2. 謎解きを決める（電話番号、張り紙のヒント、電話をかける→幽霊が反応、など）
3. 電話機を調べて番号を押せる画面を作る
4. 脱出の条件とエンディング（バス停・道の先へ出る）を作る
5. 幽霊が追いかけてくる、電話が突然鳴る、などの怖い演出を足す

## 決めたこと

- 別の分野なので、副業の2つとは分けて `games/` に置く
- 単体のHTMLで動かす（インストール不要）。遊ぶときはネットが必要
