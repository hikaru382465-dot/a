# ゲームのしくみ 実装計画（Opus 5.5 が設計 / 2026-10-04）

UE 5.8.0・Blueprint中心（C++は使わない）。ノードは「Pythonで骨組み＋貼り付け用テキスト＋手でつなぐ手順書」の3点セットで配る。

## 作るもの（/Game/KoushuDenwa/Game/）
- BP_KD_GameMode / BP_KD_Player（歩く・見回す・Eで調べる・Fで懐中電灯）
- BP_KD_Director（レベルに1個。状態管理の本体）、BP_KD_EventTrigger（再利用部品）
- BP_KD_Ghost（最初は仮の姿）、BP_KD_Newspaper / BP_KD_PhoneInteract、BPI_KD_Interact
- WBP_KD_HUD / WBP_KD_Paper / WBP_KD_Dial（テンキー）/ WBP_KD_End
- 画像：張り紙12枚＋ヒント張り紙＋新聞（PILで作る）。音：Freesound(CC0)
- 決まり：Tickを使わない。毎フレームのFind/GetAllActors禁止。参照はPythonが入れるか BeginPlay で1回だけ。

## 状態
Explore →(BoothEnter) Trapped[Idle→Flicker→Dark, Stage1〜4] →(0714) Opened →(BoothExit) Escaped
Stage5 または 70秒 → Dead → 失敗画面。番号まちがいはNG表示＋待ち時間を短縮。

## 段階
1. 歩く→ボックスに入る→ドアが閉まる→ライト点滅（setup_game.py、貼り付けテスト）
2. 張り紙・幽霊（仮）・字幕・失敗画面
3. 掲示板と新聞・ダイヤル・脱出
4. 仕上げ（幽霊をBlender/Mixamoに、音、3Dキー、調整）

## 注意
GameModeを設定しないと空飛ぶカメラになる／ボックスは Use Complex as Simple／Lumenの遅れと自動露出で暗転が弱まる／軽さ：TREE_COUNT 40、仮想メモリ32〜64GB。

# 謎解き 改訂（ひかるの追加指示 / 2026-10-04）※この節がいちばん新しい。上の表と食い違う所はこちらが優先

長さは約20分に合わせなくてよい。超えてよい。

## 外の配置（最初の指示どおり）
入口の看板 → 森の道（ゆるくくねる）→ 途中の掲示板（提灯が目印・古い新聞の切り抜き）→ 木の張り紙 → 奥の公衆電話。10円1枚目は道ばた。

## お金と電話（選択肢を増やす）
- 10円は複数（道ばた1・ボックス内1〜2・金庫の中など）。1枚ではかけ足りない。**テレフォンカード**（電話機の下のふたの中）があれば、10円なしで何回かかけられる。
- ボックス内の電話帳（本）に番号が並ぶ。ほとんどは外れ。かけるたびに10円（またはカードの度数）が減る：
  | 番号 | 結果 |
  |---|---|
  | 117 | 時報。7月14日 ○時 を告げる（ヒント） |
  | 177 | 天気予報。ノイズ混じり。年号のヒント |
  | 104 | 番号案内の自動音声。「0115 はご利用いただけません」など |
  | 110 / 119 | 話し中のツーツー（液晶に文字が出る） |
  | メモの番号 | 次の謎のヒント |
  | 自宅 | 留守電。主人公の声 |
- **幽霊は声を出さない**（出すと怖さが薄れる）。ヒントは、普通の録音音声・ノイズ・液晶の文字で出す。

## 液晶ボード（警察・消防の欄）の演出：3種
1. 文字（「でられない」「うしろ」など。触れるたびに変わる）
2. **ボックスの中の自分が映る**（ボックス内カメラ → 液晶に表示。途中で映像に何かが混じる）
3. **外のカメラ映像**（幽霊とボックスの間にカメラがあり、幽霊が近づいてくるのが映る）
作り方：SceneCaptureComponent2D → レンダーターゲット → 液晶の材質（Python）。重いので解像度は小さく、必要な時だけ更新する。

## アイテム
10円・テレカ・小さな鍵・扉の鍵・**プロテイン**（最初からインベントリにある）。

## エンディング3つ
1. **脱出エンド**：ボタン式金庫 0714 → 扉の鍵 → 普通に脱出
2. **バッドエンド（行方不明）**：時間切れ／幽霊が近づききる／ずっと電話を無駄にかけて詰む → 「◯◯大学の学生が行方不明に」（新聞風の画面）
3. **ドアぶっ壊しエンド**：主人公の趣味は筋トレと心霊スポット。インベントリのプロテインを飲む → 電話機にコマンド（仮：**2929**＝ニクニク。ヒントは主人公の財布のジムのメモ）→ 扉をぶっ壊して脱出（ギャグ寄り。扉が吹っ飛ぶ演出＋力こぶのカット）
