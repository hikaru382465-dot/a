# ガラスの文字のフォント置き場

好きな手書き・筆のフォント（.ttf / .otf）を、ここに入れると、`blender/make_game_textures.py` の `make_glass_texts()` がそれを使う。
名前に `glass` が入っているファイルを優先する（例：`glass_YujiBoku.ttf`）。無ければ、ふつうのゴシック体に「手書きのゆがみ・かすれ・垂れ」をかけて作る。

おすすめ（Google Fonts・商用利用OK・OFL）：Yuji Boku（筆）／Yuji Syuku／Zen Kurenaido（手書き）／Yomogi（手書き）
買った・配布元の規約が厳しいフォントは、GitHubに上げない。
